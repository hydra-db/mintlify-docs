---
title: "Composio"
description: "Expose HydraDB recall and ingest as agent-callable tools in Composio."
---

The HydraDB [Composio](https://composio.dev) custom app exposes HydraDB as
agent-callable tools, so any agent built on Composio can recall context and
store knowledge.

## Tools

| Tool | Endpoint | What it does |
| --- | --- | --- |
| `recall_context` | `POST /query` | Recall relevant context for a query. |
| `ingest_knowledge` | `POST /context/ingest` | Store a note as knowledge. |

## Setup

1. In the Composio dashboard or SDK, add a custom app and import the app's
   `openapi.yaml`.
2. Configure bearer auth using `integrations.yaml`. The token is your HydraDB
   API key, sent as a Bearer token.
3. Connect an account with your HydraDB API key.

The two tools are then available to agents through a Composio session.

<Note>
  The database (tenant) is carried in each request body, so a single app works
  across databases. For the full HydraDB tool set, register the HydraDB MCP
  server (`mcp.hydradb.com`) as a Composio Custom MCP connector instead of this
  app. See [MCP](/plugins/mcp).
</Note>
