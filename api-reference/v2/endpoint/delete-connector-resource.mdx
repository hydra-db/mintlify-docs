---
title: "Delete Connector Resource"
description: "Remove a resource mapping from a connector."
openapi: "api-reference/v2/openapi.json DELETE /connectors/{id}/resources/{resource_id}"
---

import { Field } from "/snippets/field.jsx";

Stop syncing a resource by removing its mapping from the connector. Content already
ingested from that resource is not removed.

<RequestExample>

```python Python SDK
resp = client.connectors.delete_resource(
    id="conn_abc123",
    resource_id="C0123456789",
)
```

```typescript TypeScript SDK
const resp = await client.connectors.deleteResource({
  id: "conn_abc123",
  resourceId: "C0123456789",
});
```

```bash cURL
curl -X DELETE 'https://api.hydradb.com/connectors/conn_abc123/resources/C0123456789' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2"
```

</RequestExample>

<ResponseExample>

```json Success
{
  "connector_id": "conn_abc123",
  "resource_id": "C0123456789",
  "deleted": true
}
```

</ResponseExample>
