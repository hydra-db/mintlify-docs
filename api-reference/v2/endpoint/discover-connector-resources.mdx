title: "Discover Resources"
description: "List the resources a connector's credentials can reach, before choosing which to sync."
openapi: "api-reference/v2/openapi.json GET /connectors/{id}/discover"
---

Asks the provider which resources the connector's stored credentials can reach: channels, repositories, databases, tables, folders and so on. Call it before [Configure Connector](/api-reference/v2/endpoint/configure-connector) to decide what to sync.

Pass an entry's `id` as `resource_id`, together with its `resource_type` and `name`, to Configure.

Providers that sync a whole account rather than individual resources return a single entry with `id` `all` and `resource_type` `workspace`. Configure that one entry to sync everything.

For providers with many resources, page through the list with `limit` (1 to 100) and `cursor`, and keep going while `has_more` is `true`.

<RequestExample>

```python Python SDK
found = client.connectors.discover("{connector_id}")
for resource in found.resources:
    print(resource.id, resource.name, resource.resource_type)
```

```typescript TypeScript SDK
const found = await client.connectors.discover({ id: "{connector_id}" });
for (const resource of found.resources ?? []) {
  console.log(resource.id, resource.name, resource.resourceType);
}
```

```bash cURL
curl 'https://api.hydradb.com/connectors/{id}/discover' \
  -H "Authorization: Bearer $HYDRA_DB_API_KEY" \
  -H "API-Version: 2"
```

</RequestExample>

<ResponseExample>

```json 200

  "resources": [

```

</ResponseExample>

## Errors

- `404`: no connector with this id in your workspace.
- `422`: the stored credentials are no longer valid. Replace them with [Update Connector](/api-reference/v2/endpoint/update-connector).
- `400` or `502`: the provider rejected the request or could not be reached. The message carries the provider's explanation.
