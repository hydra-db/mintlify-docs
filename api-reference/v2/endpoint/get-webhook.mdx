---
title: "Get Webhook"
description: "Fetch the currently registered indexing webhook for your org."
openapi: "api-reference/v2/openapi.json GET /webhooks/indexing"
---

import { Field } from "/snippets/field.jsx";

Returns the webhook currently registered for your org - its `url`, subscribed `event_types`,
and metadata. Takes no request body.

<RequestExample>

```python Python SDK
resp = client.webhooks.get()
```

```typescript TypeScript SDK
const resp = await client.webhooks.get();
```

```bash cURL
curl 'https://api.hydradb.com/webhooks/indexing' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2"
```

</RequestExample>
