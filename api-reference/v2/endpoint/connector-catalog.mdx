---
title: "Connector Catalog"
description: "List every supported connector provider with availability, maturity, category, and sync-engine metadata."
openapi: "api-reference/v2/openapi.json GET /connector-catalog"
---

Call `GET /connector-catalog` when you need a catalog-oriented provider list before creating connectors. Prefer this endpoint for dashboard-style UIs that show availability and maturity. For credential schemas and indexed fields, use [`GET /connectors/providers`](/api-reference/v2/endpoint/list-connector-providers).

<RequestExample>

```bash cURL
curl 'https://api.hydradb.com/connector-catalog' \
  -H "Authorization: Bearer $HYDRA_DB_API_KEY" \
  -H "API-Version: 2"
```

```python Python SDK
import os
from hydra_db import HydraDB

client = HydraDB(token=os.environ["HYDRA_DB_API_KEY"])
catalog = client.catalog()
print(catalog)
```

```typescript TypeScript SDK
import { HydraDBClient } from "@hydradb/sdk";

const client = new HydraDBClient({
  token: process.env.HYDRA_DB_API_KEY,
});

const catalog = await client.catalog();
console.log(catalog);
```

</RequestExample>

## When to use this vs providers

| Goal | Endpoint |
| --- | --- |
| Show provider cards (availability, maturity, category) | `GET /connector-catalog` |
| Read credential requirements and indexed/filterable fields | `GET /connectors/providers` or `GET /connectors/providers?id={provider}` |
| Preview resources with credentials before create | [`POST /connector-discovery`](/api-reference/v2/endpoint/connector-discovery) |
