---
title: "Query Graph"
description: "Run Cypher reads and writes against a graph you manage."
openapi: "api-reference/v2/openapi.json POST /byog/query"
---

Run Cypher against one graph collection in an existing database. A collection is created on its first write; reading a collection that does not exist returns no rows. This does not change the graph HydraDB extracts from managed context.

<RequestExample>

```python Python SDK
response = client.byog.query(
    database="crm",
    collection="contacts",
    query="CREATE (p:Person {name: $name}) RETURN p",
    params={"name":"Alice"},
)
print(response.data)
```

```typescript TypeScript SDK
const response = await client.byog.query({
  database: "crm",
  collection: "contacts",
  query: "CREATE (p:Person {name: $name}) RETURN p",
  params: {"name":"Alice"},
});
console.log(response.data);
```


```bash cURL
curl -X POST 'https://api.hydradb.com/byog/query' \
  -H "Authorization: Bearer $HYDRADB_API_KEY" \
  -H "API-Version: 2" \
  -H "Content-Type: application/json" \
  -d '{
    "database": "crm",
    "collection": "contacts",
    "query": "CREATE (p:Person {name: $name}) RETURN p",
    "params": {"name": "Alice"}
  }'
```

</RequestExample>

<ResponseExample>

```json 200
{
  "success": true,
  "data": [
    {
      "p": {
        "id": 0,
        "labels": [
          "Person"
        ],
        "name": "Alice"
      }
    }
  ],
  "error": null,
  "meta": {
    "request_id": "req_byog_example",
    "latency_ms": 12.3
  }
}
```

</ResponseExample>


Pass user-supplied values through `params`, not by inserting them into the query string. The response's `data` is a list of result rows. For supported Cypher and migration examples, see [Bring Your Own Graph](/essentials/v2/bring-your-own-graph#supported-cypher).
