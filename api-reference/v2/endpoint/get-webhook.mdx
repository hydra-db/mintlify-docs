---
title: "Get Webhook"
description: "Get the registered indexing webhook configuration for this API key."
openapi: "api-reference/v2/openapi.json GET /webhooks/indexing"
---

Returns the current webhook registration for this API key. Use it to confirm which URL and events are active, and whether a signing secret is configured. The secret itself is never returned  -  only the `signing_secret_configured` flag.

<RequestExample>

```bash cURL
curl 'https://api.hydradb.com/webhooks/indexing' \
  -H "Authorization: Bearer $HYDRADB_API_KEY" \
  -H "API-Version: 2"
```

</RequestExample>

<ResponseExample>

```json 200
{
  "registered": true,
  "url": "https://api.example.com/webhooks/hydradb",
  "event_types": ["indexing.status_changed"],
  "signing_secret_configured": true
}
```

</ResponseExample>

When no webhook is registered, `registered` is `false`.
