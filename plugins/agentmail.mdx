---
title: "AgentMail"
description: "Sync AgentMail inboxes into HydraDB so agents can recall past email."
---

The HydraDB connector syncs [AgentMail](https://agentmail.to) inboxes into
HydraDB as an app source, so an agent can recall past conversations before it
replies. Each message is stored as an `app_knowledge` item of type `email` and
linked to its thread, so recall returns the whole conversation.

## Quickstart

Install the package:

```bash
pip install hydradb-agentmail-plugin
```

Set your keys and run the sync:

```bash
export AGENTMAIL_API_KEY=...   # AgentMail API key
export HYDRADB_API_KEY=...     # HydraDB API key
export HYDRADB_DATABASE=...    # target database (tenant)

agentmail-sync             # every inbox
agentmail-sync <inbox_id>  # one inbox
```

## Configuration

| Variable | Required | Description |
| --- | --- | --- |
| `AGENTMAIL_API_KEY` | yes | AgentMail API key (bearer token). |
| `HYDRADB_API_KEY` | yes | HydraDB API key. |
| `HYDRADB_DATABASE` | yes | Target HydraDB database (tenant). |
| `HYDRADB_COLLECTION` | no | Sub-tenant scope within the database. |
| `AGENTMAIL_INBOX_ID` | no | Default inbox when no argument is given. |
| `AGENTMAIL_AFTER` | no | ISO 8601 cutoff for an incremental pull. |

<Note>
  Messages use AgentMail's reply-stripped text, capped at 8000 characters. Each
  message links to its thread and to the parent it replies to, so threads and
  reply chains come back connected. Run it on a schedule for a backfill, or call
  it from a `message.received` webhook to ingest each email on arrival.
</Note>
