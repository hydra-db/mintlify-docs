---
title: "Get Metadata Schema"
description: "Read the metadata fields declared for a database."
openapi: "api-reference/v2/openapi.json GET /databases/{database}/metadata-schema"
---

Returns the database's declared metadata fields in `data.fields`, including each field's type and search settings. Use it to check which fields you can send in `metadata` before ingesting or updating context.

<RequestExample>

```python Python SDK
result = client.databases.get_metadata_schema(database="acme_corp")
```

```typescript TypeScript SDK
const result = await client.databases.getMetadataSchema({ database: "acme_corp" });
```

```bash cURL
curl 'https://api.hydradb.com/databases/acme_corp/metadata-schema' \
  -H "Authorization: Bearer $HYDRA_DB_API_KEY" \
  -H "API-Version: 2"
```

</RequestExample>

The field definitions have the same shape accepted by [Create Database](/api-reference/v2/endpoint/create-tenant) and [Update Metadata Schema](/api-reference/v2/endpoint/update-metadata-schema). Free-form `additional_metadata` fields are not part of this schema.
