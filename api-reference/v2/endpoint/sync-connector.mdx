---
title: "Sync Connector"
description: "Trigger a manual sync for a connector."
openapi: "api-reference/v2/openapi.json POST /connectors/{id}/sync"
---

import { Field } from "/snippets/field.jsx";

Start an on-demand sync workflow for a connector. Syncs also run automatically on the
connector's `sync_interval_seconds` schedule; use this to force one immediately. Returns
the workflow and run IDs so you can correlate the run in logs.

<RequestExample>

```bash cURL
curl -X POST 'https://api.hydradb.com/connectors/conn_abc123/sync' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2"
```

</RequestExample>

<ResponseExample>

```json Success
{
  "workflow_id": "connector-sync-conn_abc123",
  "run_id": "b1c2d3e4-...."
}
```

</ResponseExample>
