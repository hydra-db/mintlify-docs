Use the Segment connector to bring the following content into HydraDB.

## What syncs

The provider description lists these indexed object types:

- `source_api_calls_daily`
- `workspace_api_calls_daily`
- `events_volume_daily`
- `source_mtu_usage_daily`
- `workspace_mtu_usage_daily`

## Connect

Use provider `segment` with [Create Connector](/api-reference/v2/endpoint/create-connector), then [discover resources](/api-reference/v2/endpoint/discover-connector-resources) and [configure the resources](/api-reference/v2/endpoint/configure-connector) you want to sync. The [provider description](/api-reference/v2/endpoint/list-connector-providers) supplies the credential fields for your deployment.

## Common mistakes

- A provider page describes indexed content, not the access granted to your credentials. Select resources the connected account can read.
- Synced content is not automatically private to each person. Review [ACL enforcement](/essentials/v2/connectors#enforce-acl) and set resource access rules where needed.
