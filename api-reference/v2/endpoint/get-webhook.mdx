---
title: "Get Webhook"
description: "Fetch the currently registered indexing webhook for your org."
openapi: "api-reference/v2/openapi.json GET /webhooks/indexing"
---

import { Field } from "/snippets/field.jsx";

Returns the webhook currently registered for your org, including its `url`, subscribed
`event_types`, and whether a signing secret is configured. Takes no request body. The
secret itself is never returned; only `signing_secret_configured` indicates its presence.

<RequestExample>

```python Python SDK
resp = client.webhooks.get()
```

```typescript TypeScript SDK
const resp = await client.webhooks.get();
```

```bash cURL
curl 'https://api.hydradb.com/webhooks/indexing' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2"
```

</RequestExample>

<ResponseExample>

```json Success
{
  "success": true,
  "data": {
    "registered": true,
    "url": "https://example.com/hooks/hydradb",
    "event_types": ["indexing.status_changed"],
    "signing_secret_configured": true
  },
  "error": null,
  "meta": { "request_id": "9d13aef4-02f4-4e73-8c62-4c2601d04f9d", "latency_ms": 12.3 }
}
```

</ResponseExample>
