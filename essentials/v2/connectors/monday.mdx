Use the Monday.com connector to bring the following content into HydraDB.

## What syncs

The provider description lists these indexed object types:

- `items`
- `assets`

## Connect

Create one connector per account, using that account's credentials where required. Use a separate connector for a different account; see [account scopes](/essentials/v2/connectors#6-connect-several-accounts-from-one-provider). Shared destinations are allowed, but collection names do not authorize access.

1. Paste a Monday personal API token from Profile → Developers → My Access Tokens, or an OAuth token whose app has boards:read. A personal token inherits the user's board visibility; private boards the user cannot open will not appear in the picker.
2. A Monday personal token does not use an OAuth refresh flow. Rotate it by updating and validating the connector before revoking the prior token; OAuth installations must keep their provider refresh flow active.
3. Pick boards after connecting. Each active item becomes a searchable task containing its name and rendered column values, with board-relation columns represented as graph links. Archived/deleted items are not enumerable through Monday's board items_page API and can remain indexed until a full resync.
4. When Monday permission capture is disabled, selected board content is readable by everyone in the workspace with a persistent warning unless you set a resource access rule. Ask your administrator to enable Monday permission capture before relying on board restrictions.
5. When capture is enabled, board readers are captured from owners, subscribers, and subscribed teams. Main/public boards follow account membership; public boards in closed workspaces follow workspace membership. The token must read boards, users, teams, and workspaces (boards:read, users:read, teams:read, workspaces:read).
6. If a guest, team member, or workspace reader cannot be resolved to a complete user/email roster, resource ACL capture fails open with a persistent warning rather than storing a partial allow-list. Do not interpret board permissions as read access; those values govern editing.
7. Monday enforces GraphQL complexity budgets and daily API call limits that vary by token and account plan. The connector paginates and retries rate limits, but very large boards can require a longer sync interval.

Use provider `monday` with [Create Connector](/api-reference/v2/endpoint/create-connector), then [discover resources](/api-reference/v2/endpoint/discover-connector-resources) and [configure the resources](/api-reference/v2/endpoint/configure-connector) you want to sync. The [provider description](/api-reference/v2/endpoint/list-connector-providers) supplies the credential fields for your deployment.

## Common mistakes

- A provider page describes indexed content, not the access granted to your credentials. Select resources the connected account can read.
- Synced content is not automatically private to each person. Review [ACL enforcement](/essentials/v2/connectors#enforce-acl) and set resource access rules where needed.
- API-key requests must omit `enforce_acl`, including `false`. Only a signed-in human workspace owner or writer can change **Enforce ACL** in dashboard connector settings, and enabling it requires `acl_supported: true`.
