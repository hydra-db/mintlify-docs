---
title: "Update Connector"
description: "Change a connector's sync cadence, ingestion instructions, or stored credentials."
openapi: "api-reference/v2/openapi.json PATCH /connectors/{id}"
---

import { Field } from "/snippets/field.jsx";

Updates a connector in place. Every field is optional: send only what you want to change. An omitted field is left untouched, so this is safe to call repeatedly without re-sending state you are not changing.

Instruction and cadence changes are validated up front and committed together, so a request carrying both either applies fully or not at all.

<RequestExample>

```bash cURL
curl -X PATCH 'https://api.hydradb.com/connectors/{id}' \
  -H "Authorization: Bearer $HYDRA_DB_API_KEY" \
  -H "API-Version: 2" \
  -H "Content-Type: application/json" \
  -d '{
    "custom_instructions": "Aurora was renamed to Nimbus in January 2025; they are the same product. Index all Aurora content under Nimbus.",
    "sync_interval_seconds": 3600
  }'
```

</RequestExample>

## Path parameters

| Name | Description |
| --- | --- |
| `id` | Connector UUID returned by `POST /connectors`. |

## Request body

| Name | Description |
| --- | --- |
| <Field name="custom_instructions" type="string" /> | Free-text guidance for how this connector's documents are interpreted and indexed. Max 4,000 characters. Send `""` to clear it. Omit to leave unchanged. Applies from the next sync; already-synced documents are not re-processed. See [Custom Ingestion Instructions](/essentials/v2/connector-instructions). |
| <Field name="sync_interval_seconds" type="integer" /> | How often the connector syncs. Validated against the provider's own bounds and rejected (not clamped) when out of range; `next_sync_at` is recomputed so a new cadence takes effect immediately rather than after the old interval elapses. |
| <Field name="credentials" type="object" /> | Replacement credential bundle, merged over the stored one. Clears any needs-reauth flag on success. |

## Response

| Name | Description |
| --- | --- |
| <Field name="custom_instructions_updated" type="boolean" /> | Present when this request set or cleared the instructions. |
| <Field name="credentials_updated" type="boolean" /> | Present when this request rewrote the credential bundle. |
| <Field name="sync_interval_seconds" type="integer" /> | The cadence now in force. |
| <Field name="next_sync_at" type="string" /> | When the next sync is due, recomputed if the cadence changed. |
| <Field name="min_sync_interval_seconds" type="integer" /> | Lowest cadence this provider accepts. |
| <Field name="max_sync_interval_seconds" type="integer" /> | Highest cadence this provider accepts. |

<ResponseExample>

```json 200
{
  "connector_id": "{connector_id}",
  "sync_interval_seconds": 3600,
  "next_sync_at": "2026-03-14T10:00:00Z",
  "min_sync_interval_seconds": 300,
  "max_sync_interval_seconds": 604800,
  "custom_instructions_updated": true
}
```

</ResponseExample>

## Errors

| Status | Cause |
| --- | --- |
| `400` | `custom_instructions` exceeds 4,000 characters, or `sync_interval_seconds` falls outside the provider's bounds. Nothing is changed. |
| `404` | No connector with this id in your organization. |
