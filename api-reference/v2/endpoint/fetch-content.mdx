Read what HydraDB stored for one knowledge source or memory by `id`: the original (as text or base64), a presigned download URL, or both. Use it to show a source in your app, feed it to a model, or let a user download it.

<RequestExample>

```python Python SDK
file = client.context.inspect(
    id="policy_main",
    database="acme_corp",
    mode="both",
    expiry_seconds=3600,
)
```

```typescript TypeScript SDK
const file = await client.context.inspect({
  id: "policy_main",
  database: "acme_corp",
  mode: "both",
  expirySeconds: 3600,
});
```

```bash cURL
curl -G 'https://api.hydradb.com/context/inspect' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2" \
  --data-urlencode "id=policy_main" \
  --data-urlencode "database=acme_corp" \
  --data-urlencode "mode=both" \
  --data-urlencode "expiry_seconds=3600"
```

</RequestExample>

## Query parameters

| Name | Description |
| --- | --- |
| <Field name="id" type="string" required /> | ID of the source to fetch. |
| <Field name="database" type="string" required /> | Owning database. Deprecated alias: `tenant_id`. |
| <Field name="collection" type="string or null" /> | Collection scope. If omitted, the default collection is used. Deprecated alias: `sub_tenant_id`. (default=`null`) |
| <Field name="mode" type="&#x22;content&#x22; or &#x22;url&#x22; or &#x22;both&#x22;" /> | What to return. See [Fetch modes](#fetch-modes). (default=`"both"`) |
| <Field name="expiry_seconds" type="integer" /> | Lifetime of the presigned URL in seconds, when `mode` includes `url`. From `60` to `604800` (7 days). (default=`3600`) |
| <Field name="acl" type="string[]" /> | Principals to answer as (document ACLs). A source they cannot see returns the same `404` as a missing one. Repeated (`acl=a&acl=b`) or comma-separated. Omit for no ACL scoping. See [Access Control](/essentials/v2/access-control). |

## Fetch modes

- **`content`:** the stored bytes. Valid UTF-8 (plain text, Markdown, CSV, memory text, app sources) comes back as text in `content`; anything else (PDF, DOCX, images) comes back base64-encoded in `content_base64`. The other field is `null`. Use it to render content or feed another model.
- **`url`:** only `presigned_url`, valid for `expiry_seconds`; `content`, `content_base64`, and `inferred_content` are `null`. Use it when a client should download the original directly, bypassing your backend.
- **`both` (default):** everything `content` returns, plus `presigned_url`. Use it for a UI that shows text inline with a "Download original" link.

`content` and `both` also return `inferred_content` when available: the model-derived text for the source. For memories it is the inferred statement (for example `"User prefers concise answers and dark mode."`). For knowledge it is typically `null`.

## Behavior notes

<Info>
  **You get the stored original, not parsed text.** Check both `content` and `content_base64` when you handle unknown content types.
</Info>

- **Recently ingested sources:** you get the stored original right away, but `inferred_content` stays `null` until processing produces it. If you need it, check [Ingestion Status](/api-reference/v2/endpoint/source-status) first.
- **Presigned URL lifetime:** anyone with the URL can download the file for `expiry_seconds`, so treat it as a short-lived secret.
- **Memory items:** a text memory comes back as plain text in `content`, a conversation memory as its stored JSON (`user_name` and `pairs`). Memories are stored like files, so `mode=url` and `mode=both` also return a `presigned_url`.

## Errors

- **`400 INVALID_INPUT`:** missing `id` or `database`, an unknown `mode`, or `expiry_seconds` that is not an integer or is outside `60` to `604800`.
- **`404 DATABASE_NOT_FOUND`:** the database does not exist.
- **`404 NOT_FOUND`:** the source does not exist, or `acl` is set and its principals may not see it.
- **`500 INTERNAL_ERROR`:** a transient storage error. Retry.

See [Error Responses](/api-reference/v2/error-responses).
