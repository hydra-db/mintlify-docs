---
title: "Retry Delivery"
description: "Queue a failed webhook delivery to be attempted again."
openapi: "api-reference/v2/openapi.json POST /webhooks/indexing/deliveries/{delivery_id}/retry"
---

Queues a `failed` or `permanently_failed` delivery for another attempt. Use it after fixing the problem on your side, such as a receiver that was down or was rejecting valid signatures. For a delivery in any other state, the call returns `queued: false` and nothing is retried.

The retry is signed with your **current** signing secret, not the one in force when the delivery was first attempted. If you have rotated since, your receiver must know the new secret.

See [Webhooks](/essentials/v2/webhooks) for retry and backoff behaviour.

<RequestExample>

```python Python SDK
result = client.webhooks.retry_delivery("{delivery_id}")
```

```typescript TypeScript SDK
const result = await client.webhooks.retryDelivery({ deliveryId: "{delivery_id}" });
```

```bash cURL
curl -X POST 'https://api.hydradb.com/webhooks/indexing/deliveries/{delivery_id}/retry' \
  -H "Authorization: Bearer $HYDRA_DB_API_KEY" \
  -H "API-Version: 2"
```

</RequestExample>
