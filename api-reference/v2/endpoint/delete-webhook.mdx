---
title: "Delete Webhook"
description: "Remove the webhook registration for your workspace."
openapi: "api-reference/v2/openapi.json DELETE /webhooks/indexing"
---

Removes the webhook registration. HydraDB stops sending deliveries, and the stored signing secret is discarded along with the registration.

To stop signing deliveries while keeping the webhook itself, call `DELETE /webhooks/indexing/signing-secret` instead. See [Manage the signing secret](/essentials/v2/webhooks#manage-the-signing-secret).
