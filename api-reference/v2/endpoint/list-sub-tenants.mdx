---
title: "List Collections"
description: "List collection IDs inside a database."
openapi: "api-reference/v2/openapi.json GET /databases/collections"
---

Collections are created implicitly, so a new database returns an empty list until your first write.

- **Default collection:** the first ingest without an explicit `collection` creates the default collection. It then stores all context written without a `collection`.
- **Other collections:** ingesting under a new `collection` value creates that collection. Create them at any time to scope data to users, teams, or projects, and the list grows as your application writes.

<RequestExample>

```python Python SDK
response = client.databases.collections(database="my_first_database")
```

```typescript TypeScript SDK
const response = await client.databases.collections({
  database: "my_first_database",
});
```

```bash cURL
curl -X GET 'https://api.hydradb.com/databases/collections?database=my_first_database' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2"
```

</RequestExample>
