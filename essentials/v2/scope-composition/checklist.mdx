---
title: "Scope Composition Checklist"
description: "Production checklist for HydraDB database, collection, collections fanout, metadata filters, and dual-store query scope."
---

---

## Tenancy

- [ ] Each customer org has its own `database` (B2B)
- [ ] Prod and staging use separate databases
- [ ] Session → `database` resolution is server-side only
- [ ] No “security by metadata” across customers

---

## Partitions

- [ ] Collection map documented (user / workspace / channel / project)
- [ ] Ingest always sets the intended `collection` (or deliberately uses default)
- [ ] Query uses the same ids via `collection` or `collections`
- [ ] Default collection reserved for intentionally shared Knowledge when that is your design

---

## Dual-store

- [ ] Shared Knowledge partition ≠ user Memory partition is handled via dual query or multi-`collections`
- [ ] No feature relies on `type: "all"` + user-only collection when Knowledge is shared elsewhere
- [ ] Citation/prompt code knows which store each hit came from when both are used

---

## Fanout

- [ ] `collections` allowlist derived from authz every request
- [ ] Fanout size kept practical (hard max 100)
- [ ] Weighted objects used only for ranking, never to “half-authorize”
- [ ] Ingest still writes one collection per call

---

## Metadata filters

- [ ] Hot filters declared in database metadata schema
- [ ] Filters used for attributes inside a partition — not as user/tenant replacement
- [ ] No array-as-OR/IN assumptions
- [ ] Multi-value ACL uses collections fanout or parallel queries + union

---

## Connector / Slack-style ACL

- [ ] Prefer `collection = channel_id` (or equivalent boundary)
- [ ] Query `collections` = caller’s allowed channels only
- [ ] Unscoped company-wide `query_apps` disabled for mixed private/public corpora

---

## Ops

- [ ] Empty-result runbook checks status → database → collections → type → filters
- [ ] Logs include `database` + collection list (not raw secrets)
- [ ] Alerts on sudden empty-result spikes after deploys that change scope maps
