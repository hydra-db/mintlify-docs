HydraDB is a native [Hermes Agent](https://hermes-agent.nousresearch.com/docs/)
**memory provider**: it retrieves relevant context before each turn and saves
completed turns automatically. It uses only the public HydraDB API
(`POST /query` and `POST /context/ingest`), so no HydraDB SDK is required.

## Quickstart

<Steps>
  <Step title="Install the provider">
    Requires **Python 3.10+** and a Hermes Agent install.

    <Tabs>
      <Tab title="Catalog (recommended)">
        HydraDB is a first-party entry in the curated Hermes plugin catalog:

        ```bash
        hermes plugins install hydradb
        hermes memory setup hydradb
        ```
      </Tab>
      <Tab title="Directory (drop-in)">
        Clone the repo and copy the `hydradb_hermes/` folder (it contains
        `__init__.py` and `plugin.yaml`) into your Hermes memory plugins
        directory:

        ```bash
        git clone https://github.com/hydra-db/hydradb-hermes-plugin.git
        mkdir -p ~/.hermes/plugins/memory/hydradb/
        cp -r hydradb-hermes-plugin/hydradb_hermes/. ~/.hermes/plugins/memory/hydradb/
        ```
      </Tab>
      <Tab title="pip (from GitHub)">
        ```bash
        pip install git+https://github.com/hydra-db/hydradb-hermes-plugin.git
        ```

        Registered through the `hermes_agent.memory_providers` entry point. The package is not on PyPI yet.
      </Tab>
    </Tabs>
  </Step>

  <Step title="Get credentials">
    - Create an API key from the [HydraDB dashboard](https://dashboard.hydradb.com/keys)
    - Create or copy your database ID from the [HydraDB dashboard](https://dashboard.hydradb.com/databases)
  </Step>

  <Step title="Set environment variables">
    ```bash
    export HYDRADB_API_KEY="your-api-key"
    export HYDRADB_DATABASE="your-database"
    ```
  </Step>

  <Step title="Enable it in `config.yaml`">
    Memory providers are single-select:

    ```yaml
    memory:
      provider: hydradb
    ```
  </Step>
</Steps>

## How it works

The provider implements Hermes' `MemoryProvider` contract:

| Method | Role | HydraDB |
| ------ | ---- | ------- |
| `prefetch(query, *, session_id)` | Runs before each turn and returns graph-enriched context, which Hermes injects before the API call | Hybrid `POST /query` (prefers the server-built `llm_prompt`) |
| `sync_turn(user, assistant, ...)` | Runs after each turn and saves the user/assistant exchange off-thread, so the model never waits on a write | `POST /context/ingest` |
| `is_available()` | Provider availability | `bool(HYDRADB_API_KEY)` |
| `get_config_schema()` / `save_config()` | Setup wizard (API key, database) | |
| `name` | Provider name | `"hydradb"` |

## MCP alternative

For tools the agent invokes itself instead of automatic memory, point Hermes at
the HydraDB [MCP server](/plugins/mcp). The memory provider already retrieves
and saves context automatically, so MCP is optional.
