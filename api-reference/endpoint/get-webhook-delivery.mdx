---
title: "Get Delivery"
description: "Read one webhook delivery by ID."
openapi: "api-reference/openapi.json GET /webhooks/indexing/deliveries/{delivery_id}"
---

Returns one delivery, including its current status, attempt count, and the last error code and message when an attempt failed.

<RequestExample>

```python Python SDK
delivery = client.webhooks.get_delivery("{delivery_id}")
```

```typescript TypeScript SDK
const delivery = await client.webhooks.getDelivery({ deliveryId: "{delivery_id}" });
```

```bash cURL
curl 'https://api.hydradb.com/webhooks/indexing/deliveries/{delivery_id}' \
  -H "Authorization: Bearer $HYDRADB_API_KEY" \
  -H "API-Version: 2"
```

</RequestExample>

The `delivery_id` is the value sent in the `X-HydraDB-Delivery-ID` header of the delivery itself, so you can look up any request your endpoint received. See [Webhooks](/api-reference/endpoint/webhooks-overview).
