---
title: "Database Status"
description: "Check the readiness of a database's infrastructure."
openapi: "api-reference/v2/openapi.json GET /databases/status"
---

Database creation is asynchronous. Poll this endpoint until the database is ready, then ingest or query.

For a single check, read `infra.ready_for_ingestion`. It is `true` only when all four underlying signals are `true`:

- `infra.scheduler_status` (lifecycle provisioning has finished; `false` while the database is still being created, even if some collections already exist)
- `infra.graph_status` (the graph layer)
- `infra.vectorstore_status.knowledge`
- `infra.vectorstore_status.memories`

<RequestExample>

```python Python SDK
response = client.databases.status(database="my_first_database")

if response.data.infra.ready_for_ingestion:
    print("Database is ready.")
```

```typescript TypeScript SDK
const response = await client.databases.status({
  database: "my_first_database",
});

if (response.data?.infra?.readyForIngestion) {
  console.log("Database is ready.");
}
```

```bash cURL
curl -X GET 'https://api.hydradb.com/databases/status?database=my_first_database' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2"
```

</RequestExample>

**Stale database IDs:** if `database` does not exist, the call returns `404 DATABASE_NOT_FOUND`. Confirm that `POST /databases` succeeded before you poll.

**Querying too early:** a `POST /query` sent before `ready_for_ingestion` is `true` returns `422 TENANT_INFRA_NOT_READY`.
