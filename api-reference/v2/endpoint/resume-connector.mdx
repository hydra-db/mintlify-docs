---
title: "Resume Connector"
description: "Put a paused connector back on its sync schedule."
openapi: "api-reference/v2/openapi.json POST /connectors/{id}/resume"
---

Puts a paused connector back on its schedule and makes it due for a sync right away. Each resource continues from its saved sync position, so changes made in the source app during the pause are picked up on that sync.

<RequestExample>

```bash cURL
curl -X POST 'https://api.hydradb.com/connectors/{id}/resume' \
  -H "Authorization: Bearer $HYDRA_DB_API_KEY" \
  -H "API-Version: 2"
```

</RequestExample>

<ResponseExample>

```json 200
{
  "connector_id": "{connector_id}",
  "paused": false
}
```

</ResponseExample>

## Errors

- `404`: no connector with this id in your workspace.
- `409`: the connector is not paused.
