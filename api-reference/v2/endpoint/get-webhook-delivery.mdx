---
title: "Get Webhook Delivery"
description: "Get a single indexing webhook delivery attempt by ID."
openapi: "api-reference/v2/openapi.json GET /webhooks/indexing/deliveries/{delivery_id}"
---

Fetches one delivery attempt, including status, attempt count, and any error details. Use this after listing deliveries when you need the full record for a specific `delivery_id`.

<RequestExample>

```bash cURL
curl 'https://api.hydradb.com/webhooks/indexing/deliveries/dlv_9f8e7d6c' \
  -H "Authorization: Bearer $HYDRA_DB_API_KEY" \
  -H "API-Version: 2"
```

</RequestExample>

## Path parameters

| Name | Description |
| --- | --- |
| `delivery_id` | Delivery ID returned by [List Webhook Deliveries](/api-reference/v2/endpoint/list-webhook-deliveries). |

<ResponseExample>

```json 200
{
  "delivery_id": "dlv_9f8e7d6c",
  "doc_id": "HydraDoc1234",
  "event_type": "indexing.status_changed",
  "indexing_status": "completed",
  "status": "failed",
  "attempts": 2,
  "error_code": "HTTP_TIMEOUT",
  "error_message": "Receiver did not respond in time",
  "created_at": "2026-07-02T10:00:00Z",
  "updated_at": "2026-07-02T10:00:05Z"
}
```

</ResponseExample>
