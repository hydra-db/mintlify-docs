---
title: "List Graph Collections"
description: "List the graph collections within a database."
openapi: "api-reference/v2/openapi.json GET /byog/collections"
---

List collections for a graph you manage. An unknown database returns `404`. This endpoint does not list managed context collections.

<RequestExample>

```python Python SDK
response = client.byog.list_collections(
    database="crm",
)
print(response.data)
```

```typescript TypeScript SDK
const response = await client.byog.listCollections({
  database: "crm",
});
console.log(response.data);
```


```bash cURL
curl 'https://api.hydradb.com/byog/collections?database=crm' \
  -H "Authorization: Bearer $HYDRADB_API_KEY" \
  -H "API-Version: 2"
```

</RequestExample>

<ResponseExample>

```json 200
{
  "success": true,
  "data": {
    "database": "crm",
    "collections": [
      "contacts"
    ]
  },
  "error": null,
  "meta": {
    "request_id": "req_byog_example",
    "latency_ms": 12.3
  }
}
```

</ResponseExample>


The response's `data.collections` is a list of collection names. Use a name as `collection` on [Query Graph](/api-reference/v2/endpoint/byog-query).
