---
title: "List Connector Resources"
description: "List a connector's configured resources and their settings."
openapi: "api-reference/v2/openapi.json GET /connectors/{id}/resources"
---

Returns every resource configured on a connector, with its settings: display name, the collection it routes to, metadata, `custom_instructions` when the resource has its own, and `acl` when it has an access rule.

`provider_cursor` is the resource's saved sync position. It is empty until the resource's first sync completes. For whether each resource is actually working, use [Get Connector Status](/api-reference/v2/endpoint/get-connector-status).

The `resource_id` values returned here are the ones to use in `PATCH` and `DELETE /connectors/{id}/resources/{resource_id}`.

<RequestExample>

```bash cURL
curl 'https://api.hydradb.com/connectors/{id}/resources' \
  -H "Authorization: Bearer $HYDRA_DB_API_KEY" \
  -H "API-Version: 2"
```

</RequestExample>

<ResponseExample>

```json 200
{
  "resources": [
    {
      "connector_id": "{connector_id}",
      "resource_id": "C0123456789",
      "resource_type": "channel",
      "display_name": "general",
      "status": "active",
      "provider_cursor": "{cursor}",
      "database_override": "",
      "collection_override": "all-hands",
      "tenant_id_override": "",
      "sub_tenant_id_override": "all-hands",
      "custom_instructions": "Prioritize decisions and owners.",
      "provider_metadata": null,
      "filters": {
        "lookback_days": 30
      }
    }
  ]
}
```

</ResponseExample>

`database_override` and `collection_override` are empty when the resource uses the connector's database and collection. `tenant_id_override` and `sub_tenant_id_override` repeat them under their deprecated names.
