---
title: "Pause Connector"
description: "Stop a connector's scheduled syncs until you resume it."
openapi: "api-reference/v2/openapi.json POST /connectors/{id}/pause"
---

Stops scheduling syncs for a connector. A sync that is already running stops at its next step. The connector keeps its credentials, resources and each resource's saved sync position, so [Resume Connector](/api-reference/v2/endpoint/resume-connector) continues from where it stopped and nothing created in the meantime is skipped.

While paused, `lifecycle` reads `paused` and [Sync Connector](/api-reference/v2/endpoint/sync-connector) returns `409`.

<RequestExample>

```bash cURL
curl -X POST 'https://api.hydradb.com/connectors/{id}/pause' \
  -H "Authorization: Bearer $HYDRA_DB_API_KEY" \
  -H "API-Version: 2"
```

</RequestExample>

<ResponseExample>

```json 200
{
  "connector_id": "{connector_id}",
  "paused": true,
  "paused_at": "2026-06-01T12:00:00Z"
}
```

</ResponseExample>

## Errors

- `404`: no connector with this id in your workspace.
- `409`: the connector is already paused.
