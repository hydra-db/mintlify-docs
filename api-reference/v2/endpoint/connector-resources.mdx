List the resource mappings currently configured on a connector - the resources it actively syncs.

<RequestExample>

```bash cURL
curl 'https://api.hydradb.com/connectors/<connector_id>/resources' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2"
```

</RequestExample>
