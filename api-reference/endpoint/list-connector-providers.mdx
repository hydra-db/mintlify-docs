Returns the catalog of providers you can connect, in display order. With `id={provider}`, it describes that one provider instead: the credentials it needs and the fields you can search and filter on.

Use a catalog entry's `provider` value as `provider` in [Create Connector](/api-reference/endpoint/create-connector), and as `id` here to read that provider's `credential_schema`.

<RequestExample>

```python Python SDK
catalog = client.list_providers()

affinity = client.list_providers(id="affinity")
```

```typescript TypeScript SDK
const headers = { Authorization: `Bearer ${process.env.HYDRADB_API_KEY}` };
const catalog = await client.listProviders({}, { headers });

const affinity = await client.listProviders({ id: "affinity" }, { headers });
```

```bash cURL
curl 'https://api.hydradb.com/connectors/providers' \
  -H "Authorization: Bearer $HYDRADB_API_KEY" \
  -H "API-Version: 2"

curl 'https://api.hydradb.com/connectors/providers?id=affinity' \
  -H "Authorization: Bearer $HYDRADB_API_KEY" \
  -H "API-Version: 2"
```

## The catalog

Providers with a `null` `rank` are listed last, alphabetically.

`enforce_acl` can only be enabled for a connector when its provider reports `acl_supported: true`; see [ACL on synced content](/essentials/connectors#enforce-acl).

## One provider

- `credential_schema` is the JSON Schema for `credentials` on [Create Connector](/api-reference/endpoint/create-connector) and [Update Connector](/api-reference/endpoint/update-connector).
- `searchable_fields` are values written into each synced source's text. A query finds them, but you cannot target one field on its own.
- `filterable_fields` are exact-match filters. Each entry's `filter_key` is where the value lives in `metadata_filters`.

A `filter_key` such as `additional_metadata.container_id` is written as a nested object in a query:

```json Filtering by a provider field
{
  "database": "acme_corp",
  "query": "diligence notes",
  "metadata_filters": {
    "additional_metadata": { "container_id": "12345" }
  }
}
```

A `filter_key` with no prefix, such as `connector_id`, goes directly under `metadata_filters`.

For Gmail, filter on `account_email` (`additional_metadata.account_email`) to scope results to one connected mailbox.

## Errors

- `404`: with `id`, no provider has that id. Check it against the catalog.
