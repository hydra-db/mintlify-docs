---
title: "Get Delivery"
description: "Retrieve a single webhook delivery attempt by ID."
openapi: "api-reference/v2/openapi.json GET /webhooks/indexing/deliveries/{delivery_id}"
---

Returns one delivery record, including its current status, attempt count, and the last error code and message when an attempt failed.

The `delivery_id` is the value sent in the `X-HydraDB-Delivery-ID` header of the delivery itself, so you can look up any request your endpoint received. See [Webhooks](/essentials/v2/webhooks).
