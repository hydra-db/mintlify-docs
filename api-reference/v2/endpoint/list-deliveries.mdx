---
title: "List Deliveries"
description: "List recent webhook delivery attempts, with filtering and cursor pagination."
openapi: "api-reference/v2/openapi.json GET /webhooks/indexing/deliveries"
---

import { Field } from "/snippets/field.jsx";

Returns recent delivery attempts for your registered webhook, useful for debugging
failures and auditing what HydraDB sent. Filter by `status` (for example `failed`) and
page with `limit` plus the `next_cursor` returned by the previous call.

<RequestExample>

```python Python SDK
resp = client.webhooks.list_deliveries(
    limit=50,
    status="failed",   # optional: filter by delivery status
)
```

```typescript TypeScript SDK
const resp = await client.webhooks.listDeliveries({
  limit: 50,
  status: "failed", // optional: filter by delivery status
});
```

```bash cURL
curl -G 'https://api.hydradb.com/webhooks/indexing/deliveries' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2" \
  --data-urlencode "limit=50" \
  --data-urlencode "status=failed"
```

</RequestExample>
