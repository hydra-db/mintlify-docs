The HydraDB plugin for [OpenCode](https://opencode.ai) provides a `hydradb_recall` tool for
the agent to call, syncs workspace docs when files change, and captures turns
when the session becomes idle.

## Quickstart

<Steps>
  <Step title="Install and set credentials">
    Requires [Bun](https://bun.sh) (OpenCode's runtime) and Node.js 18+.

    Add the plugin to your `opencode.json`. OpenCode installs [hydradb-opencode-plugin](https://www.npmjs.com/package/hydradb-opencode-plugin) from npm:

    ```json
    { "plugin": ["hydradb-opencode-plugin"] }
    ```

    ```bash
    export HYDRADB_API_KEY="your-api-key"
    export HYDRADB_DATABASE="your-database"
    ```
  </Step>
  <Step title="Run with tool approval">
    Tool calls need approval. Run with `--auto` or approve `hydradb_recall`
    interactively:

    ```bash
    opencode run --auto "What did we decide? Use hydradb_recall."
    ```
  </Step>
</Steps>

## Configuration

This plugin runs on the same engine as the [Claude Code plugin](/plugins/claude-code), so the [modes](/plugins/claude-code#modes) and other [configuration settings](/plugins/claude-code#configuration) there apply here too.

## How it works

| OpenCode surface | Engine action |
| ---------------- | ------------- |
| `hydradb_recall` tool (agent-invocable) | Query memories and knowledge |
| `event`: `file.edited` | Incremental workspace sync |
| `event`: `session.idle` | Capture the completed turn |
