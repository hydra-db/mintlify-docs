Fetches one delivery attempt by its `delivery_id`. Use it to check the state, attempt count, and error details for a specific event  -  for example, the `delivery_id` your receiver logged from an `X-HydraDB-Delivery-ID` header, or one taken from [List Deliveries](/api-reference/v2/endpoint/list-deliveries).

<RequestExample>

```bash cURL
curl 'https://api.hydradb.com/webhooks/indexing/deliveries/<delivery_id>' \
  -H "Authorization: Bearer $HYDRADB_API_KEY" \
  -H "API-Version: 2"
```

</RequestExample>

## Path parameters

| Name | Description |
| --- | --- |
| <Field name="delivery_id" type="string" required /> | Delivery ID from a webhook payload (`delivery_id` field or `X-HydraDB-Delivery-ID` header) or from the delivery list. |

<ResponseExample>

```json 200
{
  "delivery_id": "<delivery_id>",
  "doc_id": "<id>",
  "status": "failed",
  "indexing_status": "completed",
  "event_type": "indexing.status_changed",
  "attempts": 3,
  "error_code": "<error_code>",
  "error_message": "<error_message>",
  "created_at": "<ISO-8601 timestamp>",
  "updated_at": "<ISO-8601 timestamp>"
}
```

</ResponseExample>

`404` is returned when the `delivery_id` does not exist for this API key.
