---
title: "List Connector Resources"
description: "List the configured resources for a connector."
openapi: "api-reference/v2/openapi.json GET /connectors/{id}/resources"
---

import { Field } from "/snippets/field.jsx";

List the resource mappings currently configured on a connector: the resources it
actively syncs, with their destination overrides and status.

<RequestExample>

```python Python SDK
resp = client.connectors.list_resources(id="conn_abc123")
```

```typescript TypeScript SDK
const resp = await client.connectors.listResources({ id: "conn_abc123" });
```

```bash cURL
curl 'https://api.hydradb.com/connectors/conn_abc123/resources' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2"
```

</RequestExample>

<ResponseExample>

```json Success
{
  "resources": [
    {
      "connector_id": "conn_abc123",
      "resource_id": "C0123456789",
      "resource_type": "channel",
      "display_name": "general",
      "status": "live",
      "sub_tenant_id_override": "team_docs",
      "provider_metadata": {},
      "filters": {}
    }
  ]
}
```

</ResponseExample>
