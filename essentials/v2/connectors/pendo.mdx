Use the Pendo connector to bring the following content into HydraDB.

## What syncs

The provider description lists these indexed object types:

- `accounts`
- `events`
- `feature_events`
- `features`
- `guide_events`
- `guides`
- `metadata_accounts`
- `metadata_visitors`
- `page_events`
- `pages`
- `poll_events`
- `track_events`
- `track_types`
- `visitor_history`
- `visitors`

## Connect

Use provider `pendo` with [Create Connector](/api-reference/v2/endpoint/create-connector), then [discover resources](/api-reference/v2/endpoint/discover-connector-resources) and [configure the resources](/api-reference/v2/endpoint/configure-connector) you want to sync. The [provider description](/api-reference/v2/endpoint/list-connector-providers) supplies the credential fields for your deployment.

## Common mistakes

- A provider page describes indexed content, not the access granted to your credentials. Select resources the connected account can read.
- Synced content is not automatically private to each person. Review [ACL enforcement](/essentials/v2/connectors#enforce-acl) and set resource access rules where needed.
