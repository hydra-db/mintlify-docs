title: "Create Connector"
description: "Create a connector for a provider and store its credentials."

---

import { Field } from "/snippets/field.jsx";

Create a connector for a provider (for example Slack, Notion, or Google Drive) and
securely store its credentials. The credentials are written to the secret store, never
returned. Returns the created connector, including its `connector_id`, which you use to
discover and configure resources.

`database` is the database scope the synced content lands in; `provider` and `credentials`
are required. The credential shape depends on `auth_type` (for example an `api_token` for
token-based providers).

<RequestExample>

```bash cURL
curl -X POST 'https://api.hydradb.com/connectors' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2" \
  -H "Content-Type: application/json" \
  -d '{
    "provider": "slack",
    "database": "acme_corp",
    "auth_type": "api_token",
    "credentials": { "api_token": "xoxb-..." }
  }'
```

</RequestExample>

<ResponseExample>

```json Success
{
  "connector_id": "conn_abc123",
  "org_id": "org_xyz",
  "tenant_id": "acme_corp",
  "sub_tenant_id": "",
  "name": "Acme Slack",
  "provider": "slack",
  "auth_type": "api_token",
  "status": "active",
  "credential_ref": "conn_abc123",
  "next_sync_at": "2026-07-02T11:00:00Z",
  "sync_interval_seconds": 3600,
  "deployment_id": "free",
  "plan": "free"
}
```

</ResponseExample>
