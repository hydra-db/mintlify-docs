Use the Google Ads connector to bring the following content into HydraDB.

## What syncs

The provider description lists these indexed object types:

- `accessible_customers`
- `customer_hierarchy`
- `customer`
- `customer_label`
- `label`
- `campaign_history`
- `campaign_budget`
- `campaign_criterion`
- `campaign_label`
- `campaign_performance`
- `campaign_performance_by_age_range_and_device`
- `campaign_performance_by_gender_and_device`
- `campaign_performance_by_location`
- `adgroups`
- `ad_groups_performance`
- `ad_group_ad`
- `ad_group_ad_label`
- `ad_group_criterion`
- `ad_group_label`
- `ad_listing_group_criterion`
- `audience`
- `user_interest`
- `geo_performance`
- `geo_target_constant`
- `keyword_view`
- `managed_placement_view`
- `search_term_view`
- `video`
- `click_view_report`

## Connect

Use provider `googleads` with [Create Connector](/api-reference/v2/endpoint/create-connector), then [discover resources](/api-reference/v2/endpoint/discover-connector-resources) and [configure the resources](/api-reference/v2/endpoint/configure-connector) you want to sync. The [provider description](/api-reference/v2/endpoint/list-connector-providers) supplies the credential fields for your deployment.

## Common mistakes

- A provider page describes indexed content, not the access granted to your credentials. Select resources the connected account can read.
- Synced content is not automatically private to each person. Review [ACL enforcement](/essentials/v2/connectors#enforce-acl) and set resource access rules where needed.
