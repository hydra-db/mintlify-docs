The HydraDB plugin for [Codex](https://developers.openai.com/codex) retrieves
relevant context when you send a prompt, syncs your Markdown docs into HydraDB,
and saves conversations as memories. It behaves like the
[Claude Code plugin](/plugins/claude-code) and runs on the same engine. Only the
install flow differs.

## Quickstart

<Steps>
  <Step title="Install the plugin">
    Requires **Node.js 18+** and npm.

    ```bash
    git clone https://github.com/hydra-db/hydradb-codex-plugin.git
    cd hydradb-codex-plugin
    make bootstrap
    ```

    Then add a local marketplace entry in your project's
    `.agents/plugins/marketplace.json` that points at this plugin folder, and
    enable it in `.codex/config.toml`. See the
    [Codex plugin docs](https://developers.openai.com/codex) for the current
    install flow. The public OpenAI plugin directory listing is in review; the
    local entry works today.
  </Step>

  <Step title="Get credentials">
    - Create an API key from the [HydraDB dashboard](https://dashboard.hydradb.com/keys)
    - Create or copy your database ID from the [HydraDB dashboard](https://dashboard.hydradb.com/databases)
  </Step>

  <Step title="Set environment variables">
    ```bash
    export HYDRADB_API_KEY="your-api-key"
    export HYDRADB_DATABASE="your-database"
    export HYDRADB_COLLECTION=""
    ```

    Set `HYDRADB_COLLECTION` to an empty string for the default collection,
    or a workspace-specific value for project-isolated memory.
  </Step>
</Steps>

## Configuration

The JSON config keys, modes, and environment variables are identical to the Claude Code plugin's. Its [commands](/plugins/claude-code#commands), [modes](/plugins/claude-code#modes), and other [configuration settings](/plugins/claude-code#configuration) apply to Codex unchanged.
