title: "CrewAI"
description: "Give CrewAI agents long-term memory with the HydraDB plugin."
---

The HydraDB plugin gives [CrewAI](https://crewai.com) agents external memory. Crews retrieve
relevant history on each task and save their outputs to HydraDB, so memory
survives across runs.

## Quickstart

Install the [PyPI package](https://pypi.org/project/crewai-hydradb/):

```bash
pip install crewai-hydradb
```

Then pass HydraDB to your crew as external memory:

```python
from crewai import Crew
from crewai.memory.external.external_memory import ExternalMemory
from hydradb_crewai import HydraDBClient, HydraDBStorage

client = HydraDBClient(api_key="sk_live_...", tenant_id="your-database")

crew = Crew(
    agents=[...],
    tasks=[...],
    external_memory=ExternalMemory(storage=HydraDBStorage(client)),
)
crew.kickoff()
```

<Note>
  The plugin implements CrewAI's `Storage` interface through `ExternalMemory`,
  available in **CrewAI 1.0 to 1.10**. On **1.11+**, which restructured memory
  around an embedding-based `StorageBackend`, use HydraDB over
  [MCP](/plugins/mcp) instead.
</Note>

Outputs are stored as knowledge through the public `/context/ingest` path, and
`search` uses `POST /query`.
