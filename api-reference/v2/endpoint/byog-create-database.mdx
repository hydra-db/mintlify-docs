---
title: "Create Graph Database"
description: "Create a database for a graph you manage yourself."
openapi: "api-reference/v2/openapi.json POST /byog/databases"
---

Create a database before writing your graph. An existing name returns `409`. The response reports `status: "ready"` or `status: "provisioning"`; wait for [Database Status](/api-reference/v2/endpoint/database-status) to report readiness before querying a database that is still provisioning.

<RequestExample>

```python Python SDK
response = client.byog.create_database(
    database="crm",
)
print(response.data)
```

```typescript TypeScript SDK
const response = await client.byog.createDatabase({
  database: "crm",
});
console.log(response.data);
```


```bash cURL
curl -X POST 'https://api.hydradb.com/byog/databases' \
  -H "Authorization: Bearer $HYDRADB_API_KEY" \
  -H "API-Version: 2" \
  -H "Content-Type: application/json" \
  -d '{"database": "crm"}'
```

</RequestExample>

<ResponseExample>

```json 200
{
  "success": true,
  "data": {
    "database": "crm",
    "status": "ready",
    "cluster": "shared"
  },
  "error": null,
  "meta": {
    "request_id": "req_byog_example",
    "latency_ms": 12.3
  }
}
```

</ResponseExample>


Graph collections are created on their first write through [Query Graph](/api-reference/v2/endpoint/byog-query). An existing database created through the standard database API can also hold graph collections.
