---
title: "Delete Connector"
description: "Permanently remove a connector and stop all of its syncs."
openapi: "api-reference/v2/openapi.json DELETE /connectors/{id}"
---

Deletes the connector, its configured resources and its stored credentials, and stops all of its syncs. Objects it already synced stay in your database; delete them with [Delete Context](/api-reference/v2/endpoint/delete-source) if you no longer want them.

<RequestExample>

```bash cURL
curl -X DELETE 'https://api.hydradb.com/connectors/{id}' \
  -H "Authorization: Bearer $HYDRA_DB_API_KEY" \
  -H "API-Version: 2"
```

</RequestExample>

<ResponseExample>

```json 200
{
  "connector_id": "{connector_id}",
  "deleted": true
}
```

</ResponseExample>
