Lists a provider's resources directly from supplied credentials  -  **before** any connector exists. Use it to confirm that a token works and can see the channels, repos, pages, or labels you expect, without creating a connector first and tearing it down if the credentials turn out to be wrong.

This is the pre-creation counterpart to [Discover Resources](/api-reference/v2/endpoint/discover-connector-resources), which performs the same listing for an existing connector's stored credentials.

<RequestExample>

```bash cURL
curl -X POST 'https://api.hydradb.com/connector-discovery' \
  -H "Authorization: Bearer $HYDRA_DB_API_KEY" \
  -H "API-Version: 2" \
  -H "Content-Type: application/json" \
  -d '{
    "provider": "slack",
    "credentials": { "api_token": "xoxb-..." }
  }'
```

</RequestExample>

## Request body

| Name | Description |
| --- | --- |
| <Field name="provider" type="string" required /> | Provider to preview. One of `slack`, `github`, `linear`, `notion`, `gmail`. |
| <Field name="credentials" type="object" required /> | Provider-specific credentials, in the same shape accepted by [Create Connector](/api-reference/v2/endpoint/create-connector). Fetch the authoritative shape from [`GET /connectors/providers?id=<provider>`](/api-reference/v2/endpoint/connectors-overview)  -  the response's `credential_schema` is the contract. |
| <Field name="auth_type" type="string" /> | Authentication method for the provider connection (e.g. `api_token`, `oauth`). |

<ResponseExample>

```json 200
{
  "provider": "slack",
  "resources": [
    {
      "id": "{resource_id}",
      "name": "general",
      "resource_type": "channel"
    },
    {
      "id": "{resource_id_2}",
      "name": "engineering",
      "resource_type": "channel"
    }
  ]
}
```

</ResponseExample>

## Interpreting the response

| Result | Meaning |
| --- | --- |
| `200` with resources | The credentials are valid and can see the listed resources. You can pass the same `credentials` object to [Create Connector](/api-reference/v2/endpoint/create-connector). |
| `200` with an empty `resources` list | The credentials authenticate, but can't see any syncable content. For Notion this usually means no pages have been shared with the integration; for a Slack bot token it means the app hasn't been invited to any channels. |
| `400` | Malformed request  -  missing `provider` or `credentials`, or a credential shape the provider handler doesn't recognize. |
| `502` | The provider rejected the credentials (expired, revoked, or missing scopes), or the provider API is unreachable. |

The credentials you send here are used for the single preview call only  -  nothing is stored. Credentials are persisted (encrypted) only when you create the connector.
