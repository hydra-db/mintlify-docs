---
title: "Set Signing Secret"
description: "Generate or replace the secret used to sign webhook deliveries."
openapi: "api-reference/v2/openapi.json POST /webhooks/indexing/signing-secret"
---

Generates a signing secret for an existing webhook, or replaces it with the `signing_secret` you supply. A supplied secret must contain at least 16 characters. The secret is returned once in `data.signing_secret`; store it securely, since it cannot be read back.

Rotation takes effect immediately. If you supply your own secret, configure your receiver to accept it before making this call. See [Secret rotation](/essentials/v2/webhooks#manage-the-signing-secret).

<RequestExample>

```python Python SDK
result = client.webhooks.set_signing_secret()
secret = result.data.signing_secret
```

```typescript TypeScript SDK
const result = await client.webhooks.setSigningSecret();
const secret = result.data?.signingSecret;
```

```bash cURL
curl -X POST 'https://api.hydradb.com/webhooks/indexing/signing-secret' \
  -H "Authorization: Bearer $HYDRADB_API_KEY" \
  -H "API-Version: 2"
```

</RequestExample>

To enable signing when creating a webhook, use `generate_signing_secret: true` on [Register Webhook](/api-reference/v2/endpoint/register-webhook). If no webhook is registered, this endpoint returns `404`.
