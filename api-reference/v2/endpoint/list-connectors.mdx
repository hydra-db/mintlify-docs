---
title: "List Connectors"
description: "List all connectors for your org, optionally filtered by provider."
openapi: "api-reference/v2/openapi.json GET /connectors"
---

import { Field } from "/snippets/field.jsx";

List every connector configured for the authenticated org. Pass the optional `provider`
query parameter to filter to a single provider. Credentials are never included.

<RequestExample>

```bash cURL
curl -G 'https://api.hydradb.com/connectors' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2" \
  --data-urlencode "provider=slack"
```

</RequestExample>
