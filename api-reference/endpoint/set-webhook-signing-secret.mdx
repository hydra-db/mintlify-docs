---
title: "Set Signing Secret"
description: "Generate or replace the signing secret used to sign webhook deliveries."
openapi: "api-reference/openapi.json POST /webhooks/indexing/signing-secret"
---

Generates a signing secret for an existing webhook, or replaces it with the `signing_secret` you supply. The signing secret is returned once in `data.signing_secret`; store it securely, since it cannot be read back.

<RequestExample>

```python Python SDK
result = client.webhooks.set_signing_secret()
secret = result.data.signing_secret
```

```typescript TypeScript SDK
const result = await client.webhooks.setSigningSecret();
const secret = result.data?.signingSecret;
```

```bash cURL
curl -X POST 'https://api.hydradb.com/webhooks/indexing/signing-secret' \
  -H "Authorization: Bearer $HYDRADB_API_KEY" \
  -H "API-Version: 2"
```

</RequestExample>

A supplied signing secret must contain at least 16 characters. Rotation takes effect immediately, so if you supply your own, configure your receiver to accept it before making this call. See [Manage the signing secret](/api-reference/endpoint/webhooks-overview#manage-the-signing-secret).

To enable signing when you register a webhook, use `generate_signing_secret: true` on [Register Webhook](/api-reference/endpoint/register-webhook). If no webhook is registered, this endpoint returns `404`.
