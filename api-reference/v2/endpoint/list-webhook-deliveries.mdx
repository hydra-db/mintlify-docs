Returns recent delivery attempts for the registered indexing webhook. Use this to debug failed callbacks and confirm that events reached your endpoint.

<RequestExample>

```bash cURL
curl -G 'https://api.hydradb.com/webhooks/indexing/deliveries' \
  -H "Authorization: Bearer $HYDRA_DB_API_KEY" \
  -H "API-Version: 2" \
  --data-urlencode "limit=20" \
  --data-urlencode "status=failed"
```

</RequestExample>

## Query parameters

| Name | Description |
| --- | --- |
| <Field name="limit" type="integer" /> | Max deliveries to return. |
| <Field name="cursor" type="string" /> | Pagination cursor from a previous response's `next_cursor`. |
| <Field name="status" type="string" /> | Filter by delivery status (for example `completed`, `failed`, `permanently_failed`). |
