---
title: "Preview Provider Resources"
description: "List a provider's resources from supplied credentials before creating a connector."
openapi: "api-reference/v2/openapi.json POST /connector-discovery"
---

Use `POST /connector-discovery` to validate credentials and preview syncable resources **before** you create a connector. After create, use [`GET /connectors/{id}/discover`](/api-reference/v2/endpoint/discover-connector-resources) against the saved connector instead.

Required body fields:

| Field | Purpose |
| --- | --- |
| `provider` | Provider id such as `slack`, `github`, `linear`, `notion`, or `gmail` |
| `credentials` | Provider-specific credentials, typically `{ "api_token": "..." }` or `{ "access_token": "..." }` |
| `auth_type` | Optional auth method hint such as `api_token` or `oauth` |

Optional query params for pagination (currently Notion):

| Param | Purpose |
| --- | --- |
| `cursor` | Opaque cursor from a previous `next_cursor` |
| `limit` | Max resources per page (`1`-`100`; values above `100` are clamped) |

When `cursor` or `limit` is present, continue paging while `has_more` is true. Without either param, the endpoint returns the full resource list.

<RequestExample>

```bash cURL
curl -X POST 'https://api.hydradb.com/connector-discovery' \
  -H "Authorization: Bearer $HYDRA_DB_API_KEY" \
  -H "API-Version: 2" \
  -H "Content-Type: application/json" \
  -d '{
    "provider": "slack",
    "auth_type": "api_token",
    "credentials": {
      "api_token": "xoxb-your-bot-token"
    }
  }'
```

```python Python SDK
import os
from hydra_db import HydraDB

client = HydraDB(token=os.environ["HYDRA_DB_API_KEY"])

preview = client.connectors.discover_preview(
    provider="slack",
    auth_type="api_token",
    credentials={"api_token": "xoxb-your-bot-token"},
)
print(preview)
```

```typescript TypeScript SDK
import { HydraDBClient } from "@hydradb/sdk";

const client = new HydraDBClient({
  token: process.env.HYDRA_DB_API_KEY,
});

const preview = await client.connectors.discoverPreview({
  provider: "slack",
  authType: "api_token",
  credentials: { api_token: "xoxb-your-bot-token" },
});
console.log(preview);
```

</RequestExample>

## Typical pre-create flow

```text
GET  /connector-catalog              -> pick a provider
GET  /connectors/providers?id=...    -> confirm credential fields
POST /connector-discovery            -> preview resources with temp credentials
POST /connectors                     -> create connector once the preview looks right
GET  /connectors/:id/discover        -> re-discover from the saved connector
POST /connectors/:id/configure       -> activate resources
POST /query (query_apps: true)       -> search synced app knowledge
```

## Errors

| Status | When it happens |
| --- | --- |
| `400` | Missing `provider` / `credentials`, or invalid pagination params |
| `502` | Provider rejected the credentials or was unreachable |
