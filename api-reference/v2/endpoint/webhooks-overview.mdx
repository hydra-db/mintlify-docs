The indexing webhook notifies your HTTPS endpoint when ingested content reaches a terminal state (`completed` or `errored`). Use it instead of polling [`GET /context/status`](/api-reference/v2/endpoint/source-status).

For receiver setup, payload shape, and signature verification, see the [Webhooks guide](/essentials/v2/webhooks).

<Info>
  Webhook management endpoints return their response object directly, not inside the standard v2 `{ success, data, error, meta }` envelope used by `/databases`, `/context/*`, and `/query`.
</Info>

## Endpoint references

| Endpoint | Method | Purpose |
| --- | --- | --- |
| [`/webhooks/indexing`](/api-reference/v2/endpoint/register-webhook) | `POST` | Register or replace the indexing webhook |
| [`/webhooks/indexing`](/api-reference/v2/endpoint/get-webhook) | `GET` | Get the current registration |
| [`/webhooks/indexing`](/api-reference/v2/endpoint/delete-webhook) | `DELETE` | Unregister the webhook |
| [`/webhooks/indexing/deliveries`](/api-reference/v2/endpoint/list-webhook-deliveries) | `GET` | List recent delivery attempts |
| [`/webhooks/indexing/deliveries/{delivery_id}`](/api-reference/v2/endpoint/get-webhook-delivery) | `GET` | Get a single delivery attempt |
| [`/webhooks/indexing/deliveries/{delivery_id}/retry`](/api-reference/v2/endpoint/retry-webhook-delivery) | `POST` | Retry a failed delivery |
| [`/webhooks/indexing/test`](/api-reference/v2/endpoint/test-webhook) | `POST` | Send a test delivery |

## Typical call sequence

```text
POST /webhooks/indexing                          -> register your HTTPS URL
POST /webhooks/indexing/test                     -> verify your receiver
GET  /webhooks/indexing/deliveries               -> inspect recent attempts
GET  /webhooks/indexing/deliveries/{delivery_id} -> inspect one attempt
POST /webhooks/indexing/deliveries/{id}/retry    -> retry a failed attempt
DELETE /webhooks/indexing                        -> unregister
```

## Authentication

All webhook management endpoints use your HydraDB API key:

```bash
Authorization: Bearer $HYDRA_DB_API_KEY
API-Version: 2
```

## Key concepts

- **Registration**  -  One indexing webhook per API key / org. Calling `POST /webhooks/indexing` again replaces the existing registration.
- **Delivery**  -  A record of an attempt to `POST` an event to your URL. Use the deliveries endpoints to debug failures.
- **Retry**  -  Re-queues a `failed` or `permanently_failed` delivery for another attempt.
- **Test**  -  Sends a synthetic event so you can confirm connectivity without waiting for a real indexing job.
- **Signing secret**  -  Optional. When set, HydraDB signs payloads so your receiver can verify authenticity (see the [Webhooks guide](/essentials/v2/webhooks)).
