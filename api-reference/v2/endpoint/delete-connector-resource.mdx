import { Field } from "/snippets/field.jsx";

Stop syncing a resource by removing its mapping from the connector.

<RequestExample>

```bash cURL
curl -X DELETE 'https://api.hydradb.com/connectors/<connector_id>/resources/<resource_id>' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2"
```

</RequestExample>
