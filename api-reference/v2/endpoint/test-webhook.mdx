---
title: "Test Webhook"
description: "Send a test delivery to your registered webhook endpoint."
openapi: "api-reference/v2/openapi.json POST /webhooks/indexing/test"
---

import { Field } from "/snippets/field.jsx";

Sends a sample `indexing.status_changed` payload to your registered `url` so you can
confirm your receiver is reachable and your signature verification works before real
events fire. The response reports whether the delivery succeeded and the HTTP status your
endpoint returned.

<RequestExample>

```python Python SDK
resp = client.webhooks.test()
```

```typescript TypeScript SDK
const resp = await client.webhooks.test();
```

```bash cURL
curl -X POST 'https://api.hydradb.com/webhooks/indexing/test' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2"
```

</RequestExample>

<ResponseExample>

```json Success
{
  "success": true,
  "data": {
    "delivered": true,
    "status_code": 200,
    "message": "Test delivery accepted by endpoint"
  },
  "error": null,
  "meta": { "request_id": "9d13aef4-02f4-4e73-8c62-4c2601d04f9d", "latency_ms": 12.3 }
}
```

</ResponseExample>
