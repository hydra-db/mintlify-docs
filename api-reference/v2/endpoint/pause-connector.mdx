---
title: "Pause Connector"
description: "Pause a connector's scheduled syncs until you resume it."
openapi: "api-reference/v2/openapi.json POST /connectors/{id}/pause"
---

Pauses a connector's scheduled syncs. A sync that is already running stops at its next step. The connector keeps its credentials and resources, and each resource keeps its saved sync position, so [Resume Connector](/api-reference/v2/endpoint/resume-connector) continues from there and nothing created in the meantime is skipped.

<RequestExample>

```python Python SDK
client.connectors.pause("{connector_id}")
```

```typescript TypeScript SDK
await client.connectors.pause({ id: "{connector_id}" });
```

```bash cURL
curl -X POST 'https://api.hydradb.com/connectors/{id}/pause' \
  -H "Authorization: Bearer $HYDRADB_API_KEY" \
  -H "API-Version: 2"
```

</RequestExample>

<ResponseExample>

```json 200
{
  "connector_id": "{connector_id}",
  "paused": true,
  "paused_at": "2026-06-01T12:00:00Z"
}
```

</ResponseExample>

While paused, `lifecycle` reads `paused` and [Sync Connector](/api-reference/v2/endpoint/sync-connector) returns `409`.

## Errors

- `404`: no connector with this id in your organization.
- `409`: the connector is already paused.
