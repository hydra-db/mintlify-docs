Retrieve one connector — its provider, status, sync schedule, and last-sync details — by `connector_id`.

<RequestExample>

```bash cURL
curl 'https://api.hydradb.com/connectors/<connector_id>' \n  -H "Authorization: Bearer <your_api_key>" \n  -H "API-Version: 2"
```

</RequestExample>
