---
title: "Get Connector"
description: "Fetch a single connector by ID."
openapi: "api-reference/v2/openapi.json GET /connectors/{id}"
---

import { Field } from "/snippets/field.jsx";

Retrieve one connector by `connector_id`, including its provider, status, sync schedule,
and last-sync details. Credentials are never included.

<RequestExample>

```python Python SDK
resp = client.connectors.get(id="conn_abc123")
```

```typescript TypeScript SDK
const resp = await client.connectors.get({ id: "conn_abc123" });
```

```bash cURL
curl 'https://api.hydradb.com/connectors/conn_abc123' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2"
```

</RequestExample>

<ResponseExample>

```json Success
{
  "connector_id": "conn_abc123",
  "org_id": "org_xyz",
  "tenant_id": "acme_corp",
  "sub_tenant_id": "",
  "name": "Acme Slack",
  "provider": "slack",
  "auth_type": "api_token",
  "status": "active",
  "credential_ref": "conn_abc123",
  "next_sync_at": "2026-07-02T11:00:00Z",
  "sync_interval_seconds": 3600,
  "deployment_id": "free",
  "plan": "free"
}
```

</ResponseExample>
