Registers an HTTPS endpoint to receive `indexing.status_changed` events when ingested content reaches a terminal state. Calling this endpoint again replaces the existing registration for the same API key.

Your webhook URL must be reachable from the public internet. Localhost and private network addresses are blocked.

<RequestExample>

```bash cURL
curl -X POST 'https://api.hydradb.com/webhooks/indexing' \
  -H "Authorization: Bearer $HYDRA_DB_API_KEY" \
  -H "API-Version: 2" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://api.example.com/webhooks/hydradb",
    "event_types": ["indexing.status_changed"],
    "signing_secret": "replace-with-at-least-32-characters-secret"
  }'
```

</RequestExample>

## Request body

| Name | Description |
| --- | --- |
| <Field name="url" type="string" required /> | Public HTTPS endpoint that receives webhook deliveries. |
| <Field name="event_types" type="string[]" /> | Event types to subscribe to. Today: `["indexing.status_changed"]`. |
| <Field name="signing_secret" type="string" /> | Optional secret used to sign payloads. Minimum 32 characters. Omit to disable signing. |

<ResponseExample>

```json 201
{
  "registered": true,
  "url": "https://api.example.com/webhooks/hydradb",
  "event_types": ["indexing.status_changed"],
  "signing_secret_configured": true,
  "message": "Webhook registered."
}
```

</ResponseExample>
