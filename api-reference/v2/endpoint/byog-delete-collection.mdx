---
title: "Delete Graph Collection"
description: "Delete one graph collection and all of its content."
openapi: "api-reference/v2/openapi.json DELETE /byog/collections"
---

Delete a collection from a graph you manage. Deleting a collection that does not exist also succeeds. This endpoint does not delete a managed context collection.

<Warning>
  Deleting a graph collection removes all of its nodes and relations. This cannot be undone.
</Warning>

<RequestExample>

```python Python SDK
response = client.byog.delete_collection(
    database="crm",
    collection="contacts",
)
print(response.data)
```

```typescript TypeScript SDK
const response = await client.byog.deleteCollection({
  database: "crm",
  collection: "contacts",
});
console.log(response.data);
```


```bash cURL
curl -X DELETE 'https://api.hydradb.com/byog/collections' \
  -H "Authorization: Bearer $HYDRADB_API_KEY" \
  -H "API-Version: 2" \
  -H "Content-Type: application/json" \
  -d '{"database": "crm", "collection": "contacts"}'
```

</RequestExample>

<ResponseExample>

```json 200
{
  "success": true,
  "data": {
    "database": "crm",
    "collection": "contacts",
    "deleted": true
  },
  "error": null,
  "meta": {
    "request_id": "req_byog_example",
    "latency_ms": 12.3
  }
}
```

</ResponseExample>
