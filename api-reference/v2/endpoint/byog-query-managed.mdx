---
title: "Query Managed Graph"
description: "Run read-only Cypher against a managed context graph."
openapi: "api-reference/v2/openapi.json POST /byog"
---

Read the managed graph for one database and collection with Cypher. This endpoint rejects writes and schema changes. To read or write a graph you manage yourself, use [Query Graph](/api-reference/v2/endpoint/byog-query).

<RequestExample>

```python Python SDK
response = client.byog.query_managed(
    database="acme_corp",
    collection="company_docs",
    query="MATCH (n) RETURN n LIMIT 10",
)
print(response.data)
```

```typescript TypeScript SDK
const response = await client.byog.queryManaged({
  database: "acme_corp",
  collection: "company_docs",
  query: "MATCH (n) RETURN n LIMIT 10",
});
console.log(response.data);
```


```bash cURL
curl -X POST 'https://api.hydradb.com/byog' \
  -H "Authorization: Bearer $HYDRADB_API_KEY" \
  -H "API-Version: 2" \
  -H "Content-Type: application/json" \
  -d '{
    "database": "acme_corp",
    "collection": "company_docs",
    "query": "MATCH (n) RETURN n LIMIT 10"
  }'
```

</RequestExample>

<ResponseExample>

```json 200
{
  "success": true,
  "data": [],
  "error": null,
  "meta": {
    "request_id": "req_byog_example",
    "latency_ms": 12.3
  }
}
```

</ResponseExample>


Use the same collection as ingestion. The response's `data` is a list of result rows and can be empty.
