---
title: "Delete Graph Database"
description: "Remove graph collections and a BYOG-created database."
openapi: "api-reference/v2/openapi.json DELETE /byog/databases"
---

Delete all graph collections in a database. If the database was created through [Create Graph Database](/api-reference/v2/endpoint/byog-create-database), the database is deleted too. For a database created through the standard database API, only its graph collections are removed: `data.deleted` is `false` and the database remains.

<Warning>
  This removes the graph collections and their content permanently. Check the database name before sending the request.
</Warning>

<RequestExample>

```python Python SDK
response = client.byog.delete_database(
    database="crm",
)
print(response.data)
```

```typescript TypeScript SDK
const response = await client.byog.deleteDatabase({
  database: "crm",
});
console.log(response.data);
```


```bash cURL
curl -X DELETE 'https://api.hydradb.com/byog/databases' \
  -H "Authorization: Bearer $HYDRADB_API_KEY" \
  -H "API-Version: 2" \
  -H "Content-Type: application/json" \
  -d '{"database": "crm"}'
```

</RequestExample>

<ResponseExample>

```json 200
{
  "success": true,
  "data": {
    "database": "crm",
    "deleted": true,
    "deleted_collections": [
      "contacts"
    ],
    "cluster": "shared"
  },
  "error": null,
  "meta": {
    "request_id": "req_byog_example",
    "latency_ms": 12.3
  }
}
```

</ResponseExample>
