Introduction

HydraDB is a fast graph database on object storage, purpose-built for retrieval-augmented generation. Store your knowledge, memories, and connected apps, then query them with hybrid search and graph context.

Ingesting documents

Push documents into a collection and HydraDB chunks, embeds, and indexes them automatically. From there they are queryable via hybrid recall.

curl https://api.hydradb.com/ingest \
  -H "Authorization: Bearer $HYDRA_API_KEY" \
  -d '{"database":"docs","collection":"guides","text":"..."}'
