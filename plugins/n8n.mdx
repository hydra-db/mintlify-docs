`n8n-nodes-hydradb` is a community node for [n8n](https://n8n.io): ingest
knowledge and recall context from your workflows. The node is dependency-free
and uses n8n's built-in HTTP helper.

## Operations

| Operation | What it does |
| --- | --- |
| Ingest | Store a note as knowledge (`text` plus optional `title`). |
| Query | Recall relevant context; returns one item per chunk, with the stored text, score, title, and id. |

## Credentials

The `HydraDB API` credential holds:

- **API Key** (required): sent as a Bearer token.
- **Database** (required): the database (tenant) to read and write.
- **Collection** (optional): a sub-tenant scope.
- **Base URL** (optional): defaults to `https://api.hydradb.com`.

The connection is verified against `GET /databases`.

## Build and load locally

```bash
npm install
npm run build        # outputs dist/
```

Link the package into n8n's custom directory and restart:

```bash
mkdir -p ~/.n8n/custom
ln -s "$(pwd)" ~/.n8n/custom/n8n-nodes-hydradb
```

The HydraDB node then appears in the node panel. Pick an operation and select
your HydraDB credential: Ingest writes a note, and Query returns matching
context that downstream nodes can read.
