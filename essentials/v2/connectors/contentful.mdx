Sync the entries of the Contentful spaces you select, from every environment of each space. Each entry in each environment is one document, with its text fields written as labelled lines. Task text on an entry is its own document, linked to the entry.

Contentful permissions are not imported, so every synced entry is visible to everyone who can query the collection unless you set an access rule. Only one language is kept for each field, English (en-US) first. Assets, reference fields and authors are not synced, and entries deleted in Contentful stay in HydraDB.

## Permissions

<Warning>
Contentful permissions are not imported, so **Enforce ACL** is unavailable for this connector. Every synced item is visible to everyone who can query the collection, unless you [set an access rule on the resource](/essentials/v2/connectors#set-your-own-rule-on-a-resource).
</Warning>

API-key requests must omit `enforce_acl`, including `false`. See [ACL on synced content](/essentials/v2/connectors#5-acl-native-rbac-awareness).

## Before you connect

### Credentials

Contentful uses a Content Management API token.

<ResponseField name="api_token" type="secret string" required>
A Contentful Content Management API token.
</ResponseField>

<ResponseField name="space_id" type="string" required>
The id of a Contentful space. Required, but the spaces synced are the ones you select. A space named here and not selected is not synced.
</ResponseField>

### Set it up

<Steps>
  <Step title="Create a token">
    In Contentful, create a Content Management API token.
  </Step>
  <Step title="Create the connector">
    Paste the token as `api_token` and enter a space id as `space_id`.
  </Step>
  <Step title="Select spaces">
    HydraDB lists the spaces the token can reach. Select the spaces to sync. To reach entries older than 30 days, raise `lookback_days` when you select them.
  </Step>
</Steps>

One connector reads the spaces one Content Management API token can reach.

<Accordion title="Connect through the API">

Use provider `contentful` with [Create Connector](/api-reference/v2/endpoint/create-connector). Then call [Discover Connector Resources](/api-reference/v2/endpoint/discover-connector-resources) to list the resources the connector can sync, and [Configure Connector](/api-reference/v2/endpoint/configure-connector) to choose what to sync.

</Accordion>

## Keeping in sync

- **First sync:** Each selected space reads back the window set by `lookback_days`, 30 days by default.
- **New and changed items:** Each sync reads the entries and tasks updated since the last sync.
- **Edits:** An edited entry is read again and replaces its document.
- **Deletions:** Deleted entries and tasks are not removed. They stay searchable in HydraDB.

After the first sync, HydraDB syncs every hour by default. Set `sync_interval_seconds` on the connector to change it.

## What gets synced

### On every Contentful item

<ResponseField name="updated_at" type="Searchable text, Result date">
When the entry or task was last updated, written as the `Updated` line. Sets an entry's result date, and a task's when it has no creation time.
</ResponseField>

<ResponseField name="additional_metadata.contentful_entry_id" type="Query filter">
The entry id. On an entry, picks out that entry. On a task, the entry it is on, so one key finds an entry and its tasks. Not searchable.
</ResponseField>

<ResponseField name="connector_id" type="Query filter">
Limits a query to this connector's items. Not searchable.
</ResponseField>

<ResponseField name="provider" type="Query filter">
Always `contentful`. Not searchable.
</ResponseField>

<Accordion title="Stored only, not searchable (2)">

<ResponseField name="space_id" type="Stored only">
The space id. Keeps items from different spaces apart. There is no filter on it.
</ResponseField>

<ResponseField name="environment_id" type="Stored only">
The environment id, often `master`. Keeps the same entry in different environments apart. There is no filter on it.
</ResponseField>

</Accordion>

### Entries

- **One document:** One entry in one environment.
- **Title:** The first non-empty text in the entry's `title`, `name`, `heading` or `slug` field, checking en-US first and then other languages alphabetically. An entry with none is titled `Contentful entry` and its id.
- **Text:** The entry's text fields as labelled lines: `title`, `name`, `heading` and `slug` first, then other fields alphabetically. Each field uses its first non-empty value, en-US first, then other languages alphabetically. Rich text is flattened, and links keep their URLs in brackets. Numbers, true or false values and lists of text are included. Reference fields and embedded entries or assets are left out. If no field has text, the title stands in.
- **Date:** When the entry was last updated, else when it was created.
- **Link back:** Opens the entry's editor page in the Contentful web app.
- **Files:** None. Assets, such as images and files, are not synced.

<ResponseField name="created_at" type="Result date">
When the entry was created. Sets the result date only when the update time is missing. Not searchable.
</ResponseField>

### Tasks

- **One document:** One task on an entry. Tasks come from Contentful's pending-task list for the token, not from a complete task history. Tasks with no text are skipped.
- **Title:** `Contentful task` and the task id.
- **Text:** The task text, with `Created`, `Updated` and `Parent` lines.
- **Date:** When the task was created, else when it was last updated.
- **Link back:** None.

<ResponseField name="created_at" type="Searchable text, Result date">
When the task was created, written as the `Created` line. Sets the result date.
</ResponseField>

<ResponseField name="parent_id" type="Searchable text, Graph connection">
The entry the task is on, written as the `Parent` line. Links the task to its entry.
</ResponseField>

<ResponseField name="additional_metadata.contentful_task_id" type="Query filter">
The task id. Picks out one task. Not searchable.
</ResponseField>

<Accordion title="Stored only, not searchable (1)">

<ResponseField name="status" type="Stored only">
`active` or `resolved`. A query cannot match or filter on it.
</ResponseField>

</Accordion>

**Example searches**

- What does our Pricing FAQ entry say about enterprise discounts?
- Which blog post entries mention the 2026 conference?
- What task text is attached to the homepage hero entry?

## How it fits into the graph

- Entries use the Page class.
- Tasks use the Comment class.

[Graph classes](/essentials/v2/connector-providers#graph-classes) explains each class.

**Connections Contentful creates**

- A task to the entry it is on.
- Entries are not linked to the entries or assets they reference.
- No links to items in other tools.

**People and groups**

- No people are attached. No author, assignee or editor is recorded.

**Found in the text**

The entry's text fields and the task text. HydraDB identifies people, organizations, projects and other named things in this text. To steer what it looks for, use [custom instructions](/essentials/v2/connectors#4-custom-ingestion-instructions).

## Not synced

- Spaces you did not select.
- Entries last updated before the `lookback_days` window on the first sync.
- Assets, such as images and files, and their text.
- Values of reference fields that point to other entries or assets.
- Other languages of a field once one language has a value.
- Content types, tags and taxonomy.
- Authors, assignees and editors.
- A complete task history.
- Deletions: deleted entries stay in HydraDB.
