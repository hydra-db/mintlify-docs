Create a connector for a provider (e.g. Slack, Notion, Google Drive) and securely store its credentials. Returns the created connector, including its `connector_id`.

<RequestExample>

```bash cURL
curl -X POST 'https://api.hydradb.com/connectors'   -H "Authorization: Bearer <your_api_key>" \n  -H "API-Version: 2"   -H "Content-Type: application/json"   -d '{
    "provider": "slack",
    "tenant_id": "acme_corp",
    "auth_type": "api_token",
    "credentials": { "api_token": "xoxb-..." }
  }'
```

</RequestExample>
