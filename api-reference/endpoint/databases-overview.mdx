A database is a physically isolated store for context. In most integrations you create a database once, wait for provisioning, then ingest and query inside it.

## Endpoint references

SDK methods are listed by their Python names. The TypeScript SDK uses the same names in camelCase, such as `databases.deleteCollection`.

| Endpoint | SDK method | Purpose |
| --- | --- | --- |
| [`POST /databases`](/api-reference/endpoint/create-database) | `databases.create` | Create a database. Asynchronous. |
| [`GET /databases/status`](/api-reference/endpoint/database-status) | `databases.status` | Check provisioning readiness |
| [`GET /databases`](/api-reference/endpoint/list-databases) | `databases.list` | List all databases for the organization |
| [`GET /databases/stats`](/api-reference/endpoint/database-stats) | `databases.stats` | Get row counts for a database |
| [`GET /databases/{database}/metadata-schema`](/api-reference/endpoint/get-metadata-schema) | `databases.get_metadata_schema` | Read the metadata schema |
| [`PATCH /databases/{database}/metadata-schema`](/api-reference/endpoint/update-metadata-schema) | `databases.update_metadata_schema` | Add metadata schema fields |
| [`GET /databases/collections`](/api-reference/endpoint/list-collections) | `databases.collections` | List active collections |
| [`DELETE /databases/collections`](/api-reference/endpoint/delete-collection) | `databases.delete_collection` | Permanently remove one collection. Asynchronous. |
| [`DELETE /databases`](/api-reference/endpoint/delete-database) | `databases.delete` | Permanently remove a database. Asynchronous. |

The asynchronous calls return before the work finishes. Each endpoint page explains how to confirm completion.

## Typical call sequence

1. Create the database: `POST /databases`.
2. Wait for provisioning: poll `GET /databases/status` until `infra.ready_for_ingestion` is `true`.
3. Ingest context and wait for indexing: see the [Context overview](/api-reference/endpoint/context-overview).
4. Query: see the [Query overview](/api-reference/endpoint/query-overview).
5. Inspect usage: `GET /databases/stats` returns row counts for knowledge and memories.

## Key concepts

- **Database:** A top-level isolated store, for example one per enterprise customer. See [Databases and Collections](/essentials/databases-and-collections).
- **Collection:** A group of context inside a database, created on the first write. See [Databases and Collections](/essentials/databases-and-collections).
- **Metadata schema:** Fields declared at database creation, or added later with [Update Metadata Schema](/api-reference/endpoint/update-metadata-schema), that queries can filter on. See [Metadata Filters](/essentials/metadata).
