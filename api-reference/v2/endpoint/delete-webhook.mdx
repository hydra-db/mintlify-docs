---
title: "Delete Webhook"
description: "Remove the registered indexing webhook for your org."
openapi: "api-reference/v2/openapi.json DELETE /webhooks/indexing"
---

import { Field } from "/snippets/field.jsx";

Removes your org's registered webhook. After this, HydraDB stops delivering
`indexing.status_changed` events until you [register](/api-reference/v2/endpoint/register-webhook)
a new one.

<RequestExample>

```python Python SDK
resp = client.webhooks.delete()
```

```typescript TypeScript SDK
const resp = await client.webhooks.delete();
```

```bash cURL
curl -X DELETE 'https://api.hydradb.com/webhooks/indexing' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2"
```

</RequestExample>
