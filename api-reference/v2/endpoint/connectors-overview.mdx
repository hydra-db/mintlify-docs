---
title: "Connectors"
description: "Sync content from external providers (Slack, Notion, Google Drive, ...) into HydraDB automatically."
---

Connectors keep HydraDB in sync with an external source of truth. You create a connector for a
provider, discover its resources, choose which to sync, and HydraDB ingests them on a schedule —
no manual uploads.

## Typical flow

1. **Create** a connector with provider credentials — [Create Connector](/api-reference/v2/endpoint/create-connector)
   (or preview first with [Preview Provider Resources](/api-reference/v2/endpoint/preview-connector-resources)).
2. **Discover** the account's resources — [Discover Connector Resources](/api-reference/v2/endpoint/discover-connector-resources).
3. **Configure** which resources to sync — [Configure Connector](/api-reference/v2/endpoint/configure-connector).
4. HydraDB **syncs** automatically; trigger a manual run any time — [Sync Connector](/api-reference/v2/endpoint/sync-connector).

Synced content lands as normal knowledge sources — query it via [Query](/api-reference/v2/endpoint/query).
