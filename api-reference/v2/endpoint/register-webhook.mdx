---
title: "Register Webhook"
description: "Register (or update) the indexing webhook for your org."
openapi: "api-reference/v2/openapi.json POST /webhooks/indexing"
---

import { Field } from "/snippets/field.jsx";

Register a single indexing webhook per org. HydraDB `POST`s to your `url` whenever a source
reaches a terminal indexing state (`completed` or `errored`), so you can react to ingestion
without polling [Ingestion Status](/api-reference/v2/endpoint/source-status).

<Info>
  The only supported event type is `indexing.status_changed`. If you provide a
  `signing_secret`, it must be at least **16 characters**; HydraDB uses it to sign each
  delivery so your receiver can verify authenticity.
</Info>

<RequestExample>

```python Python SDK
resp = client.webhooks.register(
    url="https://example.com/hooks/hydradb",
    event_types=["indexing.status_changed"],
    signing_secret="whsec_at_least_16_chars",
)
```

```typescript TypeScript SDK
const resp = await client.webhooks.register({
  url: "https://example.com/hooks/hydradb",
  eventTypes: ["indexing.status_changed"],
  signingSecret: "whsec_at_least_16_chars",
});
```

```bash cURL
curl -X POST 'https://api.hydradb.com/webhooks/indexing' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com/hooks/hydradb",
    "event_types": ["indexing.status_changed"],
    "signing_secret": "whsec_at_least_16_chars"
  }'
```

</RequestExample>
