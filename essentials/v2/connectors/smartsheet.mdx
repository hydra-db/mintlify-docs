Sync every row of the Smartsheet sheets you select. Each row is one document, with each non-empty cell written as a column-and-value line.

Smartsheet sharing is not imported, so every synced row is visible to everyone who can query the collection unless you set an access rule. Attachments and discussions are not synced. Rows deleted in Smartsheet stay in HydraDB.

<Note>
Smartsheet is in beta.
</Note>

## Permissions

<Warning>
Smartsheet permissions are not imported, so **Enforce ACL** is unavailable for this connector. Every synced item is visible to everyone who can query the collection, unless you [set an access rule on the resource](/essentials/v2/connectors#set-your-own-rule-on-a-resource).
</Warning>

- Smartsheet sharing is not reproduced. Set an access rule on each sheet that should be restricted.

API-key requests must omit `enforce_acl`, including `false`. See [ACL on synced content](/essentials/v2/connectors#5-acl-native-rbac-awareness).

## Before you connect

### Credentials

Smartsheet uses an API access token.

<ResponseField name="smartsheet_access_token" type="secret string" required>
A Smartsheet API access token for a user who can read the sheets.
</ResponseField>

### Set it up

<Steps>
  <Step title="Generate a token">
    In Smartsheet, generate an API access token for a user who can view the sheets you want.
  </Step>
  <Step title="Create the connector">
    Paste the token as `smartsheet_access_token`.
  </Step>
  <Step title="Select sheets">
    HydraDB lists the sheets the token can read. Select the sheets to sync. Each row of a selected sheet becomes one document.
  </Step>
</Steps>

One connector reads the sheets one token's Smartsheet user can view.

<Accordion title="Connect through the API">

Use provider `smartsheet` with [Create Connector](/api-reference/v2/endpoint/create-connector). Then call [Discover Connector Resources](/api-reference/v2/endpoint/discover-connector-resources) to list the resources the connector can sync, and [Configure Connector](/api-reference/v2/endpoint/configure-connector) to choose what to sync.

</Accordion>

## Keeping in sync

- **First sync:** A newly selected sheet reads back the window set by `lookback_days`, 30 days by default, measured on when rows were last modified.
- **New and changed items:** Each sync reads the rows modified since the last sync.
- **Edits:** A row with a changed cell is read again and updates the same document.
- **Deletions:** Deleted rows are not removed. A row deleted in Smartsheet stays searchable in HydraDB.

After the first sync, HydraDB syncs every hour by default. Set `sync_interval_seconds` on the connector to change it.

## What gets synced

### Rows

- **One document:** One row of a selected sheet.
- **Title:** The first non-empty cell in a column named `name`, `title`, `subject` or `task name`, in any case, taking columns in alphabetical order. Otherwise the first other non-empty value. Otherwise the sheet name and `row`.
- **Text:** The title, then one `Column: value` line per non-empty cell, with columns in alphabetical order, not sheet order. Cross-sheet references and predecessors appear as cell text.
- **Date:** When the row was last modified.
- **Link back:** The sheet that holds the row, not the row itself.
- **Files:** Row attachments are not synced.

<ResponseField name="Cells" type="Searchable text">
Every non-empty cell, as `Column: value`. Columns are not individual query filters. Contact and assignee columns are text only, not people in the graph.
</ResponseField>

<ResponseField name="modified_at" type="Result date">
When the row was last modified. Sets the result date and decides when a sync picks the row up. Not searchable.
</ResponseField>

<ResponseField name="additional_metadata.smartsheet_sheet" type="Query filter">
The sheet name in snake case, such as `project_tracker`. Limits a query to one sheet's rows. Different sheet names can end up with the same value, so it is not a unique sheet id. Not searchable.
</ResponseField>

<ResponseField name="connector_id" type="Query filter">
Limits a query to this connector's rows. Not searchable.
</ResponseField>

<ResponseField name="provider" type="Query filter">
Always `smartsheet`. Not searchable.
</ResponseField>

<Accordion title="Stored only, not searchable (1)">

<ResponseField name="row_id" type="Stored only">
The numeric row id. Together with the sheet, it decides which document a later sync updates.
</ResponseField>

</Accordion>

**Example searches**

- Which rows in the Project Tracker sheet are marked At Risk?
- What is the due date and owner of the Vendor onboarding task?
- Which rows in the Hiring Plan sheet changed this week?

## How it fits into the graph

- Rows use the Page class.

[Graph classes](/essentials/v2/connector-providers#graph-classes) explains each class.

**Connections Smartsheet creates**

- Each row is grouped under its sheet. Sheets are not items of their own.
- No links between rows or to other tools. Cross-sheet references and predecessors are cell text only.

**People and groups**

No people are attached to rows. Contact and assignee columns are text only.

**Found in the text**

All cell values of each row. HydraDB identifies people, organizations, projects and other named things in this text. To steer what it looks for, use [custom instructions](/essentials/v2/connectors#4-custom-ingestion-instructions).

## Not synced

- Sheets you did not select.
- Row attachments, discussions and comments.
- Cell formatting, formulas and column-type details. Only cell values are kept.
- Smartsheet sharing.
- Deletions: deleted rows stay in HydraDB.
