Native integrations bring HydraDB memory into the apps you already use. Pick an
app below for installation, configuration, and how its memory integration works.

Want to connect an MCP-compatible assistant instead? Use the [MCP setup page](/plugins/mcp).
For terminal workflows, use the [CLI](/plugins/cli).
