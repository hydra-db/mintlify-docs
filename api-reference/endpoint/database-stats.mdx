---
title: "Database Stats"
description: "Retrieve usage statistics for a database."
openapi: "api-reference/openapi.json GET /databases/stats"
---

Returns row counts for a database: one for knowledge (`data.knowledge_collection`) and one for memories (`data.memory_collection`), each summed across every collection in the database. Use it to check how much a database holds.

<RequestExample>

```python Python SDK
stats = client.databases.stats(database="my_first_database")
```

```typescript TypeScript SDK
const stats = await client.databases.stats({
  database: "my_first_database",
});
```

```bash cURL
curl -X GET 'https://api.hydradb.com/databases/stats?database=my_first_database' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2"
```

</RequestExample>

**`row_count` counts chunks, not sources:** One ingested document typically becomes many chunks (for example, a 30-page PDF can produce 100\+ rows). To count distinct sources, use [List Context](/api-reference/endpoint/list-context) with `page_size=1` and read `pagination.total`.

**Both stores always report:** Both counts are returned even if you have ingested only knowledge or only memories. An empty store reports `row_count: 0`.

**Stats are eventually consistent:** Immediately after ingestion or deletion, counts can lag until background processing completes. Check [Ingestion Status](/api-reference/endpoint/source-status) for recently ingested IDs before treating counts as final.
