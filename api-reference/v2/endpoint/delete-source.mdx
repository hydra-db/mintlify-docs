---
title: "Delete Context"
description: "Delete knowledge or memories by their IDs."
openapi: "api-reference/v2/openapi.json DELETE /context"
---

Delete one or more sources by ID. `type` selects where to delete from: `knowledge` (the default), `memory`, or `all` to delete matching IDs from both.

Send `database`, `collection`, `ids`, and `type` as top-level fields in the request body. Include the same `collection` used at ingestion. Omitting it targets the default collection.

<RequestExample>

```python Python SDK
client.context.delete(
    type="knowledge",
    database="acme_corp",
    collection="team_docs",
    ids=["policy_main", "runbook_deploy"],
)
```

```typescript TypeScript SDK
await client.context.delete({
  type: "knowledge",
  database: "acme_corp",
  collection: "team_docs",
  ids: ["policy_main", "runbook_deploy"],
});
```

```bash cURL
curl -X DELETE 'https://api.hydradb.com/context' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2" \
  -H "Content-Type: application/json" \
  -d '{
    "database": "acme_corp",
    "collection": "team_docs",
    "ids": ["policy_main", "runbook_deploy"],
    "type": "knowledge"
  }'
```

</RequestExample>

## Status codes

By default the call can return `200` even when nothing was deleted. Check `data.deleted_count` for the number deleted and `data.results[]` for each ID's outcome.

<span id="opt-in-to-honest-status-codes"></span>

### Strict status codes

Send `X-HydraDB-Delete-Status: strict` to receive error statuses when deletion fails.

| Status | Code | Meaning |
| --- | --- | --- |
| `200` | None | At least one source was deleted. Check `results[]` for each ID. |
| `404` | `NOT_FOUND` | Nothing matched the supplied IDs. |
| `409` | `SOURCE_PROCESSING` | A source is still indexing. Retry after indexing completes. |
| `500` | `INTERNAL_ERROR` | Deletion failed. Retry the request. |

A knowledge batch is not deleted while any requested source is still indexing. Check [Ingestion Status](/api-reference/v2/endpoint/source-status) before retrying.
