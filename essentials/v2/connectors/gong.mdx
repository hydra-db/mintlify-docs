Use the Gong connector to bring the following content into HydraDB.

## What syncs

The provider description lists these indexed object types:

- `calls`
- `answered_scorecards`
- `library_calls`

## Connect

1. Connect with a Gong API key pair: in Gong's Admin center open Settings → Ecosystem → API → API keys → Get API key. Only a Gong technical administrator can create one. Copy the Access Key and the Access Key Secret (the secret is shown once) and pass them as access_key and access_key_secret.
2. When creating the key, leave the TTL empty: a key minted with an expiry stops the connector on that date and every sync after it fails with 401 until a new key is pasted. Leave Trusted IPs empty too, unless you add HydraDB's egress addresses; a list that excludes them fails every request with 403.
3. The same page shows your company's API base URL. If it is not https://api.gong.io (Gong assigns some companies their own host, e.g. https://us-12345.api.gong.io), pass it as api_base_url; only *.api.gong.io hosts are accepted.
4. Gong API keys are company-wide and have no scope picker, so there is nothing to under- or over-grant. The connector reads calls (metadata, CRM context, AI brief, outline, highlights, key points, outcome, public comments, transcript), users, workspaces, the call library and coaching scorecards; it never writes to Gong and never downloads media.
5. Pick the Gong workspaces to sync in the resource-selection step; most companies have one. Each recorded call becomes one document whose body is the transcript plus Gong's summary content; each completed coaching scorecard review becomes a document linked to its call; each call filed in a public library folder becomes a document carrying the curator's note.
6. Calls Gong marks private, and coaching reviews whose visibility is not PUBLIC, are skipped by default (Gong shows them only to their owner, participants or managers). Set include_private_calls to true to index them as well.
7. Gong publishes no modified-since filter and finishes transcripts, briefs and comments after the call itself appears, so every sync re-reads the last transcript_settle_hours (default 24) of calls and re-indexes the ones whose content changed. Raise it to catch later comments, lower it (or 0) to save requests on a very high-volume account: Gong allows 10,000 API calls per company per day, shared with every other integration you run. Because of that cap, a Gong connector syncs at most every 30 minutes (the default is hourly).
8. Not synced, because Gong's API does not expose them: emails and digital interactions, Gong Engage flows and tasks, forecasts, and deleted calls (a call removed in Gong stays indexed until the connector is re-synced from scratch).

Use provider `gong` with [Create Connector](/api-reference/v2/endpoint/create-connector), then [discover resources](/api-reference/v2/endpoint/discover-connector-resources) and [configure the resources](/api-reference/v2/endpoint/configure-connector) you want to sync. The [provider description](/api-reference/v2/endpoint/list-connector-providers) supplies the credential fields for your deployment.

## Common mistakes

- A provider page describes indexed content, not the access granted to your credentials. Select resources the connected account can read.
- Synced content is not automatically private to each person. Review [ACL enforcement](/essentials/v2/connectors#enforce-acl) and set resource access rules where needed.
