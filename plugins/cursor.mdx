The HydraDB plugin for [Cursor](https://cursor.com) retrieves relevant context
on each prompt, syncs your Markdown docs into HydraDB, and saves conversations
as memories.

## Quickstart

<Steps>
  <Step title="Bootstrap and set credentials">
    Requires **Node.js 18+** and npm.

    ```bash
    git clone https://github.com/hydra-db/hydradb-cursor-plugin.git
    cd hydradb-cursor-plugin
    make bootstrap
    export HYDRADB_API_KEY="your-api-key"
    export HYDRADB_DATABASE="your-database"
    ```
  </Step>
  <Step title="Install in Cursor">
    The public Cursor marketplace listing is in review. For now, load this local
    checkout through Cursor's plugin flow (validate the layout against the
    [Cursor plugin template](https://github.com/cursor/plugin-template)).
  </Step>
</Steps>

## Configuration

This plugin runs on the same engine as the [Claude Code plugin](/plugins/claude-code), so the [modes](/plugins/claude-code#modes) and other [configuration settings](/plugins/claude-code#configuration) there apply here too.
