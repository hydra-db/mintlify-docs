---
title: "Delete Webhook"
description: "Unregister the indexing webhook for this API key."
openapi: "api-reference/v2/openapi.json DELETE /webhooks/indexing"
---

Removes the indexing webhook registration for this API key. HydraDB stops delivering events to the previously registered URL. Past delivery records remain available for inspection until they age out.

<RequestExample>

```bash cURL
curl -X DELETE 'https://api.hydradb.com/webhooks/indexing' \
  -H "Authorization: Bearer $HYDRA_DB_API_KEY" \
  -H "API-Version: 2"
```

</RequestExample>

<ResponseExample>

```json 200
{
  "deleted": true,
  "message": "Webhook unregistered."
}
```

</ResponseExample>
