---
title: "Get Delivery"
description: "Fetch a single webhook delivery attempt by ID."
openapi: "api-reference/v2/openapi.json GET /webhooks/indexing/deliveries/{delivery_id}"
---

import { Field } from "/snippets/field.jsx";

Returns the full record for one delivery attempt (request payload, response status, and any
error), identified by the `delivery_id` from [List Deliveries](/api-reference/v2/endpoint/list-deliveries).

<RequestExample>

```python Python SDK
resp = client.webhooks.get_delivery(delivery_id="dlv_1234")
```

```typescript TypeScript SDK
const resp = await client.webhooks.getDelivery({ deliveryId: "dlv_1234" });
```

```bash cURL
curl 'https://api.hydradb.com/webhooks/indexing/deliveries/dlv_1234' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2"
```

</RequestExample>
