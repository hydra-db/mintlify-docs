---
title: "Update Connector Resource"
description: "Set a resource's ingestion instructions or access-control rule."
openapi: "api-reference/v2/openapi.json PATCH /connectors/{id}/resources/{resource_id}"
---

import { Field } from "/snippets/field.jsx";

Updates one configured resource in place. Supply `custom_instructions`, `acl`, or both; at least one is required. An omitted field is left untouched.

Use this when a single resource needs different handling from the rest of its connector  -  a channel of incident retros inside a general-purpose Slack connector, for example.

<RequestExample>

```bash cURL
curl -X PATCH 'https://api.hydradb.com/connectors/{id}/resources/{resource_id}' \
  -H "Authorization: Bearer $HYDRA_DB_API_KEY" \
  -H "API-Version: 2" \
  -H "Content-Type: application/json" \
  -d '{
    "custom_instructions": "These threads are incident retros; extract root cause, impact, and owner."
  }'
```

</RequestExample>

## Path parameters

| Name | Description |
| --- | --- |
| `id` | Connector UUID returned by `POST /connectors`. |
| `resource_id` | Resource identifier as returned by `GET /connectors/:id/resources`. |

## Request body

| Name | Description |
| --- | --- |
| <Field name="custom_instructions" type="string" /> | Instructions for documents synced from this resource only. When set, they **replace** the connector-level instructions for this resource rather than adding to them. Send `""` to clear the override and inherit the connector default again. Max 4,000 characters. Applies from the next sync. See [Custom Ingestion Instructions](/essentials/v2/connector-instructions). |
| <Field name="acl" type="string[]" /> | Access-control rule for every object synced from this resource. Normalized on write; `["__public__"]` unrestricts, `[]` restricts to nobody. Applied to already-indexed documents of this resource immediately, with no re-sync. |

## Response

| Name | Description |
| --- | --- |
| <Field name="connector_id" type="string" /> | The connector this resource belongs to. |
| <Field name="resource_id" type="string" /> | The resource that was updated. |
| <Field name="custom_instructions" type="string" /> | The stored value, present when this request set or cleared it. |
| <Field name="custom_instructions_updated" type="boolean" /> | Present when this request set or cleared the instructions. |
| <Field name="acl" type="string[]" /> | The normalized rule now in force, present when this request set it. |

<ResponseExample>

```json 200
{
  "connector_id": "{connector_id}",
  "resource_id": "{resource_id}",
  "custom_instructions": "These threads are incident retros; extract root cause, impact, and owner.",
  "custom_instructions_updated": true
}
```

</ResponseExample>

## Errors

| Status | Cause |
| --- | --- |
| `400` | Neither field supplied, `custom_instructions` exceeds 4,000 characters, or the ACL rule is malformed. Nothing is changed. |
| `404` | No such connector in your organization, or no such resource on it. A resource deleted between your read and this write returns 404 rather than being recreated. |
