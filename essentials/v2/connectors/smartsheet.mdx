Use the Smartsheet connector to bring the following content into HydraDB.

## What syncs

The provider description does not enumerate fixed indexed object types. Use the setup notes below when available; the resource picker shows what your connection can select.

## Connect

Use provider `smartsheet` with [Create Connector](/api-reference/v2/endpoint/create-connector), then [discover resources](/api-reference/v2/endpoint/discover-connector-resources) and [configure the resources](/api-reference/v2/endpoint/configure-connector) you want to sync. The [provider description](/api-reference/v2/endpoint/list-connector-providers) supplies the credential fields for your deployment.

## Common mistakes

- A provider page describes indexed content, not the access granted to your credentials. Select resources the connected account can read.
- Synced content is not automatically private to each person. Review [ACL enforcement](/essentials/v2/connectors#enforce-acl) and set resource access rules where needed.
