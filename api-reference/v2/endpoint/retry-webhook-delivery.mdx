---
title: "Retry Webhook Delivery"
description: "Queue a failed or permanently failed webhook delivery for another attempt."
openapi: "api-reference/v2/openapi.json POST /webhooks/indexing/deliveries/{delivery_id}/retry"
---

Re-queues a delivery that is `failed` or `permanently_failed`. HydraDB attempts to `POST` the original event to your registered URL again.

<RequestExample>

```bash cURL
curl -X POST 'https://api.hydradb.com/webhooks/indexing/deliveries/dlv_9f8e7d6c/retry' \
  -H "Authorization: Bearer $HYDRA_DB_API_KEY" \
  -H "API-Version: 2"
```

</RequestExample>

## Path parameters

| Name | Description |
| --- | --- |
| `delivery_id` | Delivery ID of a failed or permanently failed attempt. |

<ResponseExample>

```json 200
{
  "delivery_id": "dlv_9f8e7d6c",
  "message": "Delivery queued for retry."
}
```

</ResponseExample>
