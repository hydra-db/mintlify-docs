---
title: "Configure Connector"
description: "Select the resources to sync and trigger initial sync/backfill."
openapi: "api-reference/v2/openapi.json POST /connectors/{id}/configure"
---

import { Field } from "/snippets/field.jsx";

Choose which discovered resources a connector should sync, set an optional lookback window, and kick off the initial sync (plus historical backfill when the lookback exceeds the default chunk window).

<RequestExample>

```bash cURL
curl -X POST 'https://api.hydradb.com/connectors/<connector_id>/configure'   -H "Authorization: Bearer <your_api_key>" \n  -H "API-Version: 2"   -H "Content-Type: application/json"   -d '{
    "lookback_days": 30,
    "resources": [
      { "resource_id": "C0123456789", "name": "general", "sub_tenant_id": "team_docs" }
    ]
  }'
```

</RequestExample>
