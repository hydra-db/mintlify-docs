---
title: "Get Connector"
description: "Read one connector's settings and sync state."
openapi: "api-reference/v2/openapi.json GET /connectors/{id}"
---

Returns one connector: where it syncs to, its connector-level `custom_instructions`, its sync interval, and its sync state.

`lifecycle` is the field to read for what the connector is doing: `pending_setup` (no resources configured), `ingesting` (first sync not finished), `syncing`, `active`, `paused`, or `reconnect` (the provider rejected the credentials). `status` is deprecated and always `active`. For per-resource health, use [Get Connector Status](/api-reference/v2/endpoint/get-connector-status).

<RequestExample>

```python Python SDK
connector = client.connectors.get("{connector_id}")
```

```typescript TypeScript SDK
const connector = await client.connectors.get({ id: "{connector_id}" });
```

```bash cURL
curl 'https://api.hydradb.com/connectors/{id}' \
  -H "Authorization: Bearer $HYDRA_DB_API_KEY" \
  -H "API-Version: 2"
```

</RequestExample>

## Errors

- `404`: no connector with this id in your workspace.
