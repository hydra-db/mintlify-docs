Delete a connector. This also removes its configured resources and its stored credentials. This action is irreversible.

<RequestExample>

```bash cURL
curl -X DELETE 'https://api.hydradb.com/connectors/<connector_id>' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2"
```

</RequestExample>
