---
title: "List Connectors"
description: "List every connector in your workspace."
openapi: "api-reference/v2/openapi.json GET /connectors"
---

Returns every connector in the workspace your API key belongs to. Pass `provider` to list only one provider's connectors, for example `?provider=slack`.

Each entry has the same fields as [Get Connector](/api-reference/v2/endpoint/get-connector). Read `lifecycle` for what a connector is doing, and use [Get Connector Status](/api-reference/v2/endpoint/get-connector-status) when you need per-resource health.

<RequestExample>

```bash cURL
curl 'https://api.hydradb.com/connectors' \
  -H "Authorization: Bearer $HYDRA_DB_API_KEY" \
  -H "API-Version: 2"
```

</RequestExample>
