---
title: "Update Connector Resource"
description: "Change one resource's ingestion instructions or access rule, leaving everything else as it is."
openapi: "api-reference/v2/openapi.json PATCH /connectors/{id}/resources/{resource_id}"
---

Updates one configured resource in place. Send `custom_instructions`, `acl`, or both. At least one is required, and any field you omit is left unchanged.

`resource_id` in the path is the id from [List Connector Resources](/api-reference/v2/endpoint/connector-resources), for example a Slack channel id or a Supabase `schema.table` name. URL-encode it if it contains spaces or other reserved characters.

- `custom_instructions` replaces connector-level instructions for this resource. Maximum 4,000 characters. Send `""` to inherit the connector's instructions again. Changes affect future syncs. See [Custom Ingestion Instructions](/essentials/v2/connectors#custom-ingestion-instructions).
- `acl` changes access immediately, including for synced objects. Use `["__public__"]` for public access or `[]` to deny everyone. Provider permissions may replace this rule on the next sync. See [Access Control](/essentials/v2/access-control).

<RequestExample>

```python Python SDK
client.connectors.update_resource_acl(
    "{connector_id}",
    "{resource_id}",
    request={
        "custom_instructions": "These threads are incident retros. Extract root cause, impact and owner."
    },
)
```

```typescript TypeScript SDK
await client.connectors.updateResourceAcl({
  id: "{connector_id}",
  resourceId: "{resource_id}",
  body: {
    custom_instructions: "These threads are incident retros. Extract root cause, impact and owner.",
  },
});
```

```bash cURL
curl -X PATCH 'https://api.hydradb.com/connectors/{id}/resources/{resource_id}' \
  -H "Authorization: Bearer $HYDRADB_API_KEY" \
  -H "API-Version: 2" \
  -H "Content-Type: application/json" \
  -d '{
    "custom_instructions": "These threads are incident retros. Extract root cause, impact and owner."
  }'
```

</RequestExample>

<ResponseExample>

```json 200
{
  "connector_id": "{connector_id}",
  "resource_id": "{resource_id}",
  "custom_instructions": "These threads are incident retros. Extract root cause, impact and owner.",
  "custom_instructions_updated": true
}
```

</ResponseExample>

The response includes `custom_instructions` and `acl` only when the request set them, showing the stored values.

## Errors

- `400`: neither field was sent, `custom_instructions` is over 4,000 characters, or the access rule is malformed. Nothing is changed.
- `404`: no connector with this id in your organization, or no configured resource with this `resource_id` on it.
