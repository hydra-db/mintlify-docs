Use the Freshdesk connector to bring the following content into HydraDB.

## What syncs

The provider description lists these indexed object types:

- `tickets`
- `conversations`

## Connect

1. Copy an agent API key from Freshdesk Profile settings and enter only the helpdesk subdomain: for acme.freshdesk.com, enter acme. The key has no scope picker and reads according to that agent's Global, Group or Restricted ticket scope.
2. Freshdesk API keys do not refresh automatically and are tied to the agent. Rotate by resetting or replacing the key, updating the connector, and validating a sync before disabling the prior agent credential.
3. Tickets and public replies become searchable and link back to the agent portal. Private agent notes are off by default because Freshdesk's per-agent visibility is not yet reproduced in HydraDB; when explicitly enabled they are indexed tenant-wide with an RBAC warning, so enable include_private_notes only when every tenant member may read them.
4. Freshdesk rate limits are account-wide and plan-dependent. The connector honors Retry-After on 429 responses; other apps in the same helpdesk consume the same quota.

Use provider `freshdesk` with [Create Connector](/api-reference/v2/endpoint/create-connector), then [discover resources](/api-reference/v2/endpoint/discover-connector-resources) and [configure the resources](/api-reference/v2/endpoint/configure-connector) you want to sync. The [provider description](/api-reference/v2/endpoint/list-connector-providers) supplies the credential fields for your deployment.

## Common mistakes

- A provider page describes indexed content, not the access granted to your credentials. Select resources the connected account can read.
- Synced content is not automatically private to each person. Review [ACL enforcement](/essentials/v2/connectors#enforce-acl) and set resource access rules where needed.
