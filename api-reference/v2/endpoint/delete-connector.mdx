---
title: "Delete Connector"
description: "Delete a connector, its resources, and stored credentials."
openapi: "api-reference/v2/openapi.json DELETE /connectors/{id}"
---

import { Field } from "/snippets/field.jsx";

Delete a connector. This also removes its configured resources and its stored
credentials, and stops all future syncs. Already-ingested content is not removed. This
action is irreversible.

<RequestExample>

```bash cURL
curl -X DELETE 'https://api.hydradb.com/connectors/conn_abc123' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2"
```

</RequestExample>

<ResponseExample>

```json Success
{
  "connector_id": "conn_abc123",
  "deleted": true
}
```

</ResponseExample>
