## What syncs

**Indexed object types**

- `pages`
- `driveItems`
- `listItems`

## Connect

Create one connector per account, using that account's credentials where required. Use a separate connector for a different account; see [account scopes](/essentials/v2/connectors#6-connect-several-accounts-from-one-provider). Shared destinations are allowed, but collection names do not authorize access.

1. Register a Microsoft Entra app for app-only client credentials. Copy the Directory (tenant) ID, Application (client) ID, and a client-secret Value into tenant, client_id, and client_secret; the Secret ID is not the secret value.
2. Grant Microsoft Graph APPLICATION permissions Sites.Read.All and Files.Read.All, then grant tenant-wide admin consent. Sites.Read.All is required for site discovery, document libraries, and site pages; Files.Read.All is required for drive delta metadata and file-content download. Delegated permissions do not satisfy this connector.
3. Pick the SharePoint sites to sync. Site pages and document-library files become searchable with human site, library, path, author, and MIME metadata; IDs remain provenance and stable identity rather than reader-facing labels.
4. Lists on a selected site are indexed too: every row of every visible list becomes one document holding its column values under their display names. Document libraries, hidden lists and SharePoint's own system lists are skipped, and list row attachments are not downloaded.
5. SharePoint item and site permissions are not yet reproduced. Content is readable by everyone in your HydraDB tenant, and every item carries rbac_warning; set a resource access rule for sites that must be restricted.
6. File changes use Graph drive delta and page changes use lastModifiedDateTime windows. Provider deletion signals are not fully converged into hard index deletion yet; this documented current limitation does not block initial or incremental ingestion.

Use provider `sharepoint` with [Create Connector](/api-reference/v2/endpoint/create-connector), then [discover resources](/api-reference/v2/endpoint/discover-connector-resources) and [configure the resources](/api-reference/v2/endpoint/configure-connector) you want to sync. The [provider description](/api-reference/v2/endpoint/list-connector-providers) supplies the credential fields for your deployment.

## Common mistakes

- A provider page describes indexed content, not the access granted to your credentials. Select resources the connected account can read.
- Synced content is not automatically private to each person. Review [ACL enforcement](/essentials/v2/connectors#enforce-acl) and set resource access rules where needed.
- API-key requests must omit `enforce_acl`, including `false`. Only a signed-in human workspace owner or writer can change **Enforce ACL** in dashboard connector settings, and enabling it requires `acl_supported: true`.
