---
title: "Get Webhook"
description: "Get the indexing webhook registration for this API key."
openapi: "api-reference/v2/openapi.json GET /webhooks/indexing"
---

Returns the current indexing webhook configuration for this API key, including the registered URL and whether a signing secret is configured. The secret itself is never returned.

<RequestExample>

```bash cURL
curl 'https://api.hydradb.com/webhooks/indexing' \
  -H "Authorization: Bearer $HYDRA_DB_API_KEY" \
  -H "API-Version: 2"
```

</RequestExample>

<ResponseExample>

```json 200
{
  "registered": true,
  "url": "https://api.example.com/webhooks/hydradb",
  "event_types": ["indexing.status_changed"],
  "signing_secret_configured": true
}
```

</ResponseExample>
