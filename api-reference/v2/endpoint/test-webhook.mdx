---

import { Field } from "/snippets/field.jsx";

Sends a sample `indexing.status_changed` payload to your registered `url` so you can confirm
your receiver is reachable and your signature verification works — before real events fire.

<RequestExample>

```python Python SDK
resp = client.webhooks.test()
```

```typescript TypeScript SDK
const resp = await client.webhooks.test();
```

```bash cURL
curl -X POST 'https://api.hydradb.com/webhooks/indexing/test' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2"
```

</RequestExample>
