<Warning>
**Irreversible:** deleting a database permanently removes all of its data: ingested documents, memories, embeddings, vector indices, graph nodes, metadata schema, and storage objects. There is no soft delete and no recovery window, so back up anything that matters first.

The examples use a placeholder name, `database_to_delete`. Replace it with the database you mean to destroy, and check the name twice on a shared or team account, where you may not be the only one using it.
</Warning>

<RequestExample>
```python Python SDK
response = client.databases.delete(database="database_to_delete")
```
```typescript TypeScript SDK
const response = await client.databases.delete({
  database: "database_to_delete",
});
```
```bash cURL
curl -X DELETE 'https://api.hydradb.com/databases?database=database_to_delete' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2"
```
</RequestExample>

## Deletion completion

Deletion is asynchronous. The endpoint returns as soon as the database is deregistered. Cleanup of vector stores, graphs, and storage objects runs in the background and may take a few minutes.

Treat deletion as complete when the database no longer appears in `GET /databases`, or when `GET /databases/status?database=...` returns `DATABASE_NOT_FOUND`. After that, you can reuse the same `database` in a new `POST /databases` request. Until then, do not recreate the database or retry ingestion or queries against it.

## Behavior notes

- **Stop in-flight work first:** stop all ingestion, polling, query, and background jobs that target this database before you delete it. Calls made after deregistration can fail with `DATABASE_NOT_FOUND` even while cleanup is still running.
- **Repeat calls:** deleting an already-deleted database returns `404 DATABASE_NOT_FOUND`. Deleting a database that is still deleting returns `200` again. Deleting a database that is still provisioning, or whose provisioning or earlier deletion failed, tears it down.

## Errors

Common codes: `400 INVALID_INPUT` (missing `database`), `401 UNAUTHORIZED`, `404 DATABASE_NOT_FOUND`, and `500 INTERNAL_ERROR` (transient; retry the same `DELETE`). See [Error Responses](/api-reference/v2/error-responses) for the full list.
