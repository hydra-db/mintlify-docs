<a id="codex"></a>

The HydraDB plugin for Claude Code runs in the background: it syncs your workspace docs into HydraDB on session start, retrieves relevant context before each prompt, and saves the conversation as memories after each response. The plugins for [Codex](/plugins/codex), [Cursor](/plugins/cursor), [OpenCode](/plugins/opencode), [Muse Code](/plugins/muse-code), [Grok Build](/plugins/grok-build), [OpenClaw](/plugins/openclaw), and [DeepSeek Harness](/plugins/deepseek) run on the same engine, so the [modes](#modes) and other [configuration settings](#configuration) on this page apply to them too.

## Quickstart

<Steps>
  <Step title="Install the plugin">
    Run these commands inside Claude Code:

    ```bash
    /plugin marketplace add hydra-db/hydradb-claude-code
    /plugin install hydradb@hydradb
    /reload-plugins
    ```
  </Step>

  <Step title="Get credentials">
    - Create an API key from the [HydraDB dashboard](https://dashboard.hydradb.com/keys)
    - Create or copy your database ID from the [HydraDB dashboard](https://dashboard.hydradb.com/databases)
  </Step>

  <Step title="Set environment variables">
    <Tabs>
      <Tab title="macOS/Linux (bash)">
        ```bash
        echo 'export HYDRADB_API_KEY="your-api-key"' >> ~/.bashrc
        echo 'export HYDRADB_DATABASE="your-database"' >> ~/.bashrc
        echo 'export HYDRADB_COLLECTION=""' >> ~/.bashrc
        source ~/.bashrc
        ```
      </Tab>

      <Tab title="macOS/Linux (zsh)">
        ```bash
        echo 'export HYDRADB_API_KEY="your-api-key"' >> ~/.zshrc
        echo 'export HYDRADB_DATABASE="your-database"' >> ~/.zshrc
        echo 'export HYDRADB_COLLECTION=""' >> ~/.zshrc
        source ~/.zshrc
        ```
      </Tab>

      <Tab title="Windows (PowerShell)">
        ```powershell
        [System.Environment]::SetEnvironmentVariable("HYDRADB_API_KEY", "your-api-key", "User")
        [System.Environment]::SetEnvironmentVariable("HYDRADB_DATABASE", "your-database", "User")
        [System.Environment]::SetEnvironmentVariable("HYDRADB_COLLECTION", "", "User")
        ```
      </Tab>
    </Tabs>

    `HYDRADB_COLLECTION` must be set explicitly:

    - Set it to an empty string (`""`) to use the default collection. Do not omit it.
    - Set a workspace-specific value (for example, `claude-my-project`) for project-isolated memory.
    - Set a shared value to carry memory across all sessions and workspaces.

    <Note>
      These names need plugin 1.1.0 or later. The older names `HYDRA_DB_API_KEY`, `HYDRADB_TENANT_ID`, and `HYDRADB_SUB_TENANT_ID` still work, but print a deprecation warning.
    </Note>

    To verify the values are set:

    <Tabs>
      <Tab title="macOS/Linux">
        ```bash
        test -n "$HYDRADB_API_KEY" && echo "API key is set"
        echo $HYDRADB_DATABASE
        ```
      </Tab>
      <Tab title="Windows (PowerShell)">
        ```powershell
        if ($env:HYDRADB_API_KEY) { "API key is set" }
        echo $env:HYDRADB_DATABASE
        ```
      </Tab>
    </Tabs>
  </Step>

  <Step title="Run setup and verify">
    ```bash
    /hydradb:setup
    /hydradb:status
    ```
  </Step>
</Steps>

## Commands

| Command | Description |
| ------- | ----------- |
| `/hydradb:setup` | Interactive configuration wizard |
| `/hydradb:status` | Show current config and connection status |
| `/hydradb:search <query>` | Search HydraDB manually |
| `/hydradb:remember <note>` | Save a note to memory |
| `/hydradb:save-session` | Manually save the full session to HydraDB |
| `/hydradb:sync-workspace [--force]` | Force re-sync workspace docs |

## Configuration

Set each setting below in a JSON config file. The required settings and the timeouts also have environment variables.

### Config file locations

The plugin resolves config in this order. Later sources override earlier ones:

1. Built-in defaults
2. `HYDRADB_PLUGIN_CONFIG` env var (absolute path to a JSON file)
3. `${CLAUDE_PLUGIN_DATA}/config.json`
4. `.hydradb-plugin-data/config.json`
5. `.hydradb-plugin.json` (workspace-shared, safe to commit to git)
6. `.hydradb-plugin.local.json` (workspace-local, add to `.gitignore`)
7. Environment variable overrides

### Required

| Setting       | Env var              | Description                                                                      |
| ------------- | -------------------- | -------------------------------------------------------------------------------- |
| `apiKey`      | `HYDRADB_API_KEY`    | Your HydraDB API key                                                             |
| `tenantId`    | `HYDRADB_DATABASE`   | Your HydraDB database                                                            |
| `subTenantId` | `HYDRADB_COLLECTION` | Collection within the database. No default: set to `""` for the default collection |

### Core behavior

| Setting        | Default | Description                                                      |
| -------------- | ------- | ---------------------------------------------------------------- |
| `autoRecall`   | `true`  | Inject HydraDB context before every prompt                       |
| `autoIngest`   | `true`  | Sync workspace docs on session start and on file edits           |
| `graphContext` | `true`  | Include entity paths and graph relations in the injected context |

### Modes

#### `captureMode`: how conversations are saved

| Value            | Behavior                                                                              |
| ---------------- | ------------------------------------------------------------------------------------- |
| `session-upsert` | **(default)** Maintains one evolving session transcript, upserted after each response |
| `turn`           | Saves each user/assistant exchange as an isolated memory                              |
| `both`           | Saves isolated turns and a rolling session transcript                                 |
| `off`            | No automatic saves; manual saves still work via `/hydradb:save-session`               |

<Warning>
  By default, the plugin saves every conversation pair (user and assistant) that does not include the `ignoreMarker` (`hydra-ignore`). For manual-only capture, set `captureMode` to `off` and use `/hydradb:save-session` or `/hydradb:remember <text>`.
</Warning>

#### `searchMode`: what is queried at prompt time

| Value       | Behavior                                                             |
| ----------- | -------------------------------------------------------------------- |
| `memory`    | **(default)** Queries [memories](/essentials/v2/memories) only       |
| `knowledge` | Queries [knowledge](/essentials/v2/knowledge) only                   |
| `both`      | Queries both in parallel, then merges results                        |

#### `ingestionMode`: where workspace docs are synced

| Value       | Behavior                                                                                  |
| ----------- | ----------------------------------------------------------------------------------------- |
| `memory`    | **(default)** Syncs workspace docs into memories using `infer`                            |
| `knowledge` | Syncs workspace docs into knowledge                                                       |
| `auto`      | Prefers memory; falls back to knowledge for larger files. Pair with `searchMode: "both"`  |

#### `recallMode`: speed or depth

| Value      | Behavior                                                  |
| ---------- | --------------------------------------------------------- |
| `fast`     | **(default)** Lower latency, standard retrieval           |
| `thinking` | Deeper, reasoning-based retrieval through graph traversal |

### Limits

| Setting                  | Default            | Description                                          |
| ------------------------ | ------------------ | ---------------------------------------------------- |
| `maxContextChars`        | `7000`             | Max characters injected into the prompt from HydraDB |
| `maxMemoryResults`       | `6`                | Max memory chunks returned per query                 |
| `maxKnowledgeResults`    | `4`                | Max knowledge chunks returned per query              |
| `maxFileSizeBytes`       | `52428800` (50 MB) | Max file size for workspace sync                     |
| `maxFilesPerSync`        | `25`               | Max files synced per pass                            |
| `maxMemoryCharsPerChunk` | `52428800` (50 MB) | Max chars per memory chunk                           |
| `maxMemoryChunksPerFile` | `1`                | Max chunks per file                                  |

### Timeouts

| Setting            | Env var                      | Default | Description                               |
| ------------------ | ---------------------------- | ------- | ----------------------------------------- |
| `requestTimeoutMs` | `HYDRADB_REQUEST_TIMEOUT_MS` | `15000` | Timeout for query and read requests (ms)  |
| `writeTimeoutMs`   | `HYDRADB_WRITE_TIMEOUT_MS`   | `15000` | Timeout for sync and write requests (ms)  |

### File filtering

| Setting        | Default                                                               | Description                                      |
| -------------- | --------------------------------------------------------------------- | ------------------------------------------------ |
| `includeGlobs` | `CLAUDE.md`, `.claude/**/*.md`, `**/*.md`, `**/*.mdx`                 | Files included in workspace sync                 |
| `excludeGlobs` | `.git/**`, `node_modules/**`, `dist/**`, `**/.env*`, `**/*.key`, etc. | Files excluded from workspace sync               |
| `ignoreMarker` | `hydra-ignore`                                                        | Add to a file or prompt to skip capture and sync |

To sync file types other than `.md` and `.mdx`, extend `includeGlobs` in your config file.

### Advanced

| Setting                             | Default                   | Description                                                      |
| ----------------------------------- | ------------------------- | ---------------------------------------------------------------- |
| `userName`                          | -                         | Optional user name attached to memories                          |
| `apiBaseUrl`                        | `https://api.hydradb.com` | HydraDB API base URL                                             |
| `memoryCustomInstructions`          | -                         | Custom instructions for how conversation memories are extracted  |
| `workspaceMemoryCustomInstructions` | -                         | Custom instructions for how workspace doc memories are extracted |
| `debug`                             | `false`                   | Enable debug logging to `.hydradb-plugin-data/debug.log`         |

## Suggested configurations

Pick the [mode](#modes) values that match your use case:

| Use case                                                           | `captureMode`    | `searchMode` | `ingestionMode` |
| ------------------------------------------------------------------ | ---------------- | ------------ | --------------- |
| Everyday use, cross-session continuity, or shared team knowledge   | `session-upsert` | `memory`     | `memory`        |
| Maximum retrieval coverage                                         | `both`           | `both`       | `auto`          |
| Retrieval only, no automatic saves                                 | `off`            | `memory`     | `memory`        |
| Isolated turn snapshots                                            | `turn`           | `memory`     | `memory`        |

The first row is the default, so it needs no mode settings.

### Minimal (env vars only)

```bash
export HYDRADB_API_KEY="your-api-key"
export HYDRADB_DATABASE="your-database"
export HYDRADB_COLLECTION=""
```

### Recommended workspace config (`.hydradb-plugin.json`)

```json
{
  "apiKey": "${HYDRADB_API_KEY}",
  "tenantId": "${HYDRADB_DATABASE}",
  "subTenantId": "claude-my-workspace",
  "autoRecall": true,
  "autoIngest": true,
  "captureMode": "session-upsert",
  "searchMode": "memory",
  "ingestionMode": "memory",
  "recallMode": "fast",
  "graphContext": true,
  "maxContextChars": 7000,
  "requestTimeoutMs": 15000,
  "writeTimeoutMs": 15000
}
```

### Maximum retrieval coverage

```json
{
  "captureMode": "both",
  "searchMode": "both",
  "ingestionMode": "auto",
  "maxContextChars": 10000,
  "maxMemoryResults": 8,
  "maxKnowledgeResults": 6
}
```

### Manual saves only (no automatic capture)

```json
{
  "captureMode": "off",
  "autoRecall": true,
  "autoIngest": true
}
```
