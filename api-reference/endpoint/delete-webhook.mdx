---
title: "Delete Webhook"
description: "Delete the webhook registration for your organization."
openapi: "api-reference/openapi.json DELETE /webhooks/indexing"
---

Deletes the webhook registration. HydraDB stops sending deliveries, and the stored signing secret is discarded along with the registration.

<RequestExample>

```python Python SDK
client.webhooks.delete()
```

```typescript TypeScript SDK
await client.webhooks.delete();
```

```bash cURL
curl -X DELETE 'https://api.hydradb.com/webhooks/indexing' \
  -H "Authorization: Bearer $HYDRADB_API_KEY" \
  -H "API-Version: 2"
```

</RequestExample>

To stop signing deliveries while keeping the webhook itself, call [Disable Signing](/api-reference/endpoint/disable-webhook-signing) instead. See [Manage the signing secret](/api-reference/endpoint/webhooks-overview#manage-the-signing-secret).
