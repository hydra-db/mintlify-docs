---
title: "List Databases"
openapi: "api-reference/v2/openapi.json GET /databases"
description: "List all databases created. "
---

The response separates active or provisioning databases (in `data.databases`) from databases whose provisioning failed (in `data.failed_databases`). Use [Database Status](/api-reference/v2/endpoint/tenant-status) to confirm readiness before ingestion. This endpoint takes no parameters.

<RequestExample>

```python Python SDK
response = client.databases.list()
```

```typescript TypeScript SDK
const response = await client.databases.list();
```

```bash cURL
curl -X GET 'https://api.hydradb.com/databases' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2"
```

</RequestExample>

## Retry notes

- If provisioning failed for a database, `data.failed_databases` contains diagnostic entries as shown in the **Provisioning issue** tab.
- **Retry failed databases:** Delete the failed database with `DELETE /databases`, wait until it no longer appears in `GET /databases`, then create it again with `POST /databases`. Re-creating it without deleting it first returns `409 DATABASE_ALREADY_EXISTS`.
