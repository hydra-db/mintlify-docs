---
title: "List Connectors"
description: "List all connectors for your org, optionally filtered by provider."
openapi: "api-reference/v2/openapi.json GET /connectors"
---

import { Field } from "/snippets/field.jsx";

List every connector configured for the authenticated org. Pass `provider` to filter to a single provider.

<RequestExample>

```bash cURL
curl -G 'https://api.hydradb.com/connectors' \n  -H "Authorization: Bearer <your_api_key>" \n  -H "API-Version: 2" \n  --data-urlencode "provider=slack"
```

</RequestExample>
