---
title: "Add Connector Resource"
description: "Add a resource mapping to a connector."
openapi: "api-reference/v2/openapi.json POST /connectors/{id}/resources"
---

import { Field } from "/snippets/field.jsx";

Add a single resource mapping to an existing connector, with optional per-resource database
and collection overrides (`tenant_id_override` / `sub_tenant_id_override`) and metadata.
Use this to extend an already-configured connector without re-sending its full resource
list.

<RequestExample>

```bash cURL
curl -X POST 'https://api.hydradb.com/connectors/conn_abc123/resources' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2" \
  -H "Content-Type: application/json" \
  -d '{
    "resource_id": "C0123456789",
    "display_name": "general",
    "sub_tenant_id_override": "team_docs"
  }'
```

</RequestExample>

<ResponseExample>

```json Success
{
  "connector_id": "conn_abc123",
  "resource_id": "C0123456789",
  "resource_type": "channel",
  "display_name": "general",
  "status": "live",
  "sub_tenant_id_override": "team_docs",
  "provider_metadata": {},
  "filters": {}
}
```

</ResponseExample>
