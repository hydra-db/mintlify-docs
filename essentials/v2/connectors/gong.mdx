Sync recorded calls from the Gong workspaces you select. Each call is one document holding the call details, linked CRM records, topics, Gong's AI brief, key points, highlights and outline, the full speaker-labelled transcript, and public comments. Each completed coaching review, and each call filed in a library folder, is its own document linked to the call.

Gong permissions are not imported, so every synced item is visible to everyone who can query the collection unless you set an access rule. Calls Gong marks private are skipped unless you turn them on. Changes that arrive after a call's re-read window, such as late comments, are missed. Audio and video are not synced.

## Permissions

<Warning>
Gong permissions are not imported, so **Enforce ACL** is unavailable for this connector. Every synced item is visible to everyone who can query the collection, unless you [set an access rule on the resource](/essentials/v2/connectors#set-your-own-rule-on-a-resource).
</Warning>

- Calls Gong marks private, reviews of those calls, and reviews that are not public are skipped unless you turn on `include_private_calls`. With it on, they are synced without their Gong audience. Set an access rule on the workspace if they must stay restricted.
- A call that Gong does not mark as private or public is synced. A review with no visibility is treated as public.
- If HydraDB cannot read the privacy of the call behind a review or library placement, the item still syncs, with a permission warning.

API-key requests must omit `enforce_acl`, including `false`. See [ACL on synced content](/essentials/v2/connectors#5-acl-native-rbac-awareness).

## Before you connect

### Credentials

Gong uses an API key pair, an Access Key and an Access Key Secret, created by a Gong technical administrator.

<ResponseField name="access_key" type="secret string" required>
The Gong Access Key.
</ResponseField>

<ResponseField name="access_key_secret" type="secret string" required>
The Gong Access Key Secret. Gong shows it once.
</ResponseField>

<ResponseField name="api_base_url" type="string">
The HTTPS API host shown on Gong's API keys page: `api.gong.io`, or your company's subdomain directly before `api.gong.io`. Set it only if Gong shows a company-specific address.
</ResponseField>

<ResponseField name="include_private_calls" type="boolean">
Off by default. Turn it on to also sync private calls and reviews that are not public.
</ResponseField>

<ResponseField name="transcript_settle_hours" type="number">
How many hours of recent calls every sync reads again, to catch late transcripts, briefs and comments. 24 by default.
</ResponseField>

**Gong API permissions the connector uses**

- `api:calls:read:basic`
- `api:calls:read:extensive`
- `api:calls:read:transcript`
- `api:users:read`
- `api:workspaces:read`
- `api:library:read`: optional. Without it, library placements are skipped.
- `api:settings:scorecards:read`: optional. Without it, coaching reviews are skipped.
- `api:stats:scorecards`: optional. Without it, coaching reviews are skipped.

A Gong API key pair covers the whole company and has no scope picker. The list names what the connector reads, not grants you choose. Which optional endpoints your Gong plan allows depends on your subscription.

### Set it up

<Steps>
  <Step title="Create an API key">
    In Gong's Admin center, open Settings, Ecosystem, API, API keys, and choose Get API key. Only technical administrators can do this. Copy the Access Key and the Access Key Secret.
  </Step>
  <Step title="Leave the expiry and IP limits empty">
    Leave the key's TTL empty. A key with an expiry stops the connector on that date. Leave Trusted IPs empty unless you add HydraDB's outgoing addresses, or every request fails.
  </Step>
  <Step title="Create the connector">
    Paste the Access Key as `access_key` and the secret as `access_key_secret`. If the API keys page shows a company-specific API address, enter it as `api_base_url`.
  </Step>
  <Step title="Select workspaces">
    HydraDB lists the company's Gong workspaces. Select the ones to sync. Each workspace syncs separately.
  </Step>
</Steps>

One connector reads one Gong company, through its company-wide API key.

<Accordion title="Connect through the API">

Use provider `gong` with [Create Connector](/api-reference/v2/endpoint/create-connector). Then call [Discover Connector Resources](/api-reference/v2/endpoint/discover-connector-resources) to list the resources the connector can sync, and [Configure Connector](/api-reference/v2/endpoint/configure-connector) to choose what to sync.

</Accordion>

## Keeping in sync

- **First sync:** Calls and reviews reach back the window set by `lookback_days`, 30 days by default. For calls, the window reaches back a further `transcript_settle_hours`. Library folders are read in full.
- **New and changed items:** Each sync reads calls by start time, and reads again every call that started within the last `transcript_settle_hours`, 24 by default, to catch late transcripts, briefs and comments. Reviews are read by review time. The workspace library is read in full on every sync.
- **Edits:** A call is updated only while its start time is inside the re-read window. Later changes to a call, such as a comment added after that, are missed. Raise `transcript_settle_hours` to keep calls open longer.
- **Deletions:** Calls that disappear from Gong can stay searchable in HydraDB.
- The shortest sync interval for Gong is 30 minutes.
- Gong allows a company 10,000 API calls a day. HydraDB shares that allowance with every other integration on your Gong company.

After the first sync, HydraDB syncs every hour by default. Set `sync_interval_seconds` on the connector to change it.

### Calls

- **One document:** One recorded call, with its transcript and public comments.
- **Title:** The call title, else `Gong call` and the call id.
- **Text:** The title, then `When`, `Duration`, `Direction`, `Scope`, `Host`, `Participants` with their job titles, `Related` CRM records, `Outcome`, `Topics` and `Trackers` lines. - **Date:** When the call actually started.
- **Link back:** The call in Gong.
- **Files:** None. Audio and video are never downloaded.

## How it fits into the graph

- Calls use the Meeting class.
- Coaching reviews use the Page class.
- Library placements use the Page class.

[Graph classes](/essentials/v2/connector-providers#graph-classes) explains each class.

**Connections Gong creates**

- A coaching review to the call it scores.
- A library placement to the call it files.
- CRM record ids and calendar event ids are kept for filtering only. They do not link a call to CRM or calendar documents.
- No links to other tools.

**People and groups**

- The host and every participant of each call, with their email when Gong has it.
- The author of each public comment.
- The reviewer of each coaching review, and the person who filed each library placement.
- The rep reviewed is not attached to the review as a person.

**Found in the text**

The transcript and Gong's AI content for each call, coaching review answers and curator notes. HydraDB identifies people, organizations, projects and other named things in this text. To steer what it looks for, use [custom instructions](/essentials/v2/connectors#4-custom-ingestion-instructions).

## Not synced

- Workspaces you did not select.
- Emails and other digital interactions, Engage flows and tasks, and forecasts.
- Audio and video, per-person interaction statistics, and transcript timings.
- Private calls, reviews of them, and reviews that are not public, unless `include_private_calls` is on.
- Private and archived library folders, even with `include_private_calls` on.
- Library placements or coaching reviews when Gong refuses the optional endpoint. Reviews also need access to scorecard definitions.
- Comments and other changes that arrive after a call's re-read window.
