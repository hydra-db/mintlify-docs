import { Field } from "/snippets/field.jsx";

Add a single resource mapping to an existing connector, with optional per-resource tenant/collection overrides and metadata.

<RequestExample>

```bash cURL
curl -X POST 'https://api.hydradb.com/connectors/<connector_id>/resources' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2" \
  -H "Content-Type: application/json" \
  -d '{
    "resource_id": "C0123456789",
    "display_name": "general",
    "sub_tenant_id_override": "team_docs"
  }'
```

</RequestExample>
