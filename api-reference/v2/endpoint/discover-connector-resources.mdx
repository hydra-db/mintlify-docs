---

import { Field } from "/snippets/field.jsx";

List the resources available in the connected provider account (channels, folders, pages, ...) using the connector's stored credentials. Use the returned resource IDs with [Configure Connector](/api-reference/v2/endpoint/configure-connector).

<RequestExample>

```bash cURL
curl 'https://api.hydradb.com/connectors/<connector_id>/discover' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2"
```

</RequestExample>
