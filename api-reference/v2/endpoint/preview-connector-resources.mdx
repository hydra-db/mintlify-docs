import { Field } from "/snippets/field.jsx";

Validate a provider credential and list its resources **before** creating a connector, a
flow used by onboarding wizards. Nothing is persisted: the credentials stay in memory and
are never written to the secret store. Once the user commits, create the connector with
[Create Connector](/api-reference/v2/endpoint/create-connector).

<RequestExample>

```bash cURL
curl -X POST 'https://api.hydradb.com/connector-discovery' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2" \
  -H "Content-Type: application/json" \
  -d '{
    "provider": "slack",
    "auth_type": "api_token",
    "credentials": { "api_token": "xoxb-..." }
  }'
```

</RequestExample>

<ResponseExample>

```json Success
{
  "provider": "slack",
  "resources": [
    { "id": "C0123456789", "name": "general", "resource_type": "channel", "metadata": { "is_private": false } }
  ]
}
```

</ResponseExample>
