---
title: "Retry Delivery"
description: "Re-attempt a previously failed webhook delivery."
openapi: "api-reference/v2/openapi.json POST /webhooks/indexing/deliveries/{delivery_id}/retry"
---

import { Field } from "/snippets/field.jsx";

Re-queues a specific delivery to your registered `url`. Use it after fixing a receiver
outage to replay a `failed` delivery found via
[List Deliveries](/api-reference/v2/endpoint/list-deliveries). The response confirms the
retry was queued; the outcome then shows up as a new attempt on the delivery record.

<RequestExample>

```python Python SDK
resp = client.webhooks.retry_delivery(delivery_id="dlv_1234")
```

```typescript TypeScript SDK
const resp = await client.webhooks.retryDelivery({ deliveryId: "dlv_1234" });
```

```bash cURL
curl -X POST 'https://api.hydradb.com/webhooks/indexing/deliveries/dlv_1234/retry' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2"
```

</RequestExample>

<ResponseExample>

```json Success
{
  "success": true,
  "data": {
    "delivery_id": "dlv_1234",
    "queued": true,
    "message": "Delivery re-queued"
  },
  "error": null,
  "meta": { "request_id": "9d13aef4-02f4-4e73-8c62-4c2601d04f9d", "latency_ms": 12.3 }
}
```

</ResponseExample>
