---
title: "Discover Connector Resources"
description: "List a connected provider's resources using the connector's stored credentials."
openapi: "api-reference/v2/openapi.json GET /connectors/{id}/discover"
---

import { Field } from "/snippets/field.jsx";

List the resources available in the connected provider account (channels, folders,
pages, and so on) using the connector's stored credentials. Use the returned resource
IDs with [Configure Connector](/api-reference/v2/endpoint/configure-connector) to choose
what to sync.

<RequestExample>

```python Python SDK
resp = client.connectors.discover(id="conn_abc123")
```

```typescript TypeScript SDK
const resp = await client.connectors.discover({ id: "conn_abc123" });
```

```bash cURL
curl 'https://api.hydradb.com/connectors/conn_abc123/discover' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2"
```

</RequestExample>

<ResponseExample>

```json Success
{
  "provider": "slack",
  "resources": [
    { "id": "C0123456789", "name": "general", "resource_type": "channel", "metadata": { "is_private": false } },
    { "id": "C0987654321", "name": "engineering", "resource_type": "channel", "metadata": { "is_private": true } }
  ]
}
```

</ResponseExample>
