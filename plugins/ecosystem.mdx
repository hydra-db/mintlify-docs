title: "Plugins"
description: "Add HydraDB memory to your coding agents, editors, and agent frameworks with a native plugin."
---

Plugins bring HydraDB memory into the coding agents and frameworks you already
use. Pick one below for installation, configuration, and how it works.

To connect any MCP-compatible assistant instead, use [MCP](/plugins/mcp).
For terminal workflows, use the [CLI](/plugins/cli).
