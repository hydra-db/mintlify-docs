---
title: "Sync Connector"
description: "Sync a connector now instead of waiting for its schedule."
openapi: "api-reference/v2/openapi.json POST /connectors/{id}/sync"
---

Starts a sync of every configured resource now. Connectors already sync on their own every `sync_interval_seconds` (one hour by default), and [Configure Connector](/api-reference/v2/endpoint/configure-connector) starts the first sync itself. Call this when you need fresh data sooner, or when configure answered `sync_started: false` with a `sync_error` that is `retryable`.

A `202` means the sync was started, not that it finished. Follow progress with [Get Connector Status](/api-reference/v2/endpoint/get-connector-status).

If a sync of this connector is already running, nothing new starts. The answer is `200` with `already_running: true` and the `run_id` of the running sync. That sync uses the resources and credentials it loaded when it began. To include later changes, call this endpoint again after it finishes.

<RequestExample>

```bash cURL
curl -X POST 'https://api.hydradb.com/connectors/{id}/sync' \
  -H "Authorization: Bearer $HYDRA_DB_API_KEY" \
  -H "API-Version: 2"
```

</RequestExample>

<ResponseExample>

```json 202
{
  "workflow_id": "connector-sync-{connector_id}",
  "run_id": "{run_id}",
  "already_running": false
}
```

```json 200
{
  "workflow_id": "connector-sync-{connector_id}",
  "run_id": "{running_run_id}",
  "already_running": true
}
```

</ResponseExample>

## Errors

- `404`: no connector with this id in your workspace.
- `409`: the connector is paused, or it has no active resources to sync. [Resume](/api-reference/v2/endpoint/resume-connector) it, or [configure](/api-reference/v2/endpoint/configure-connector) resources first.
- `429`: your plan's sync limit is reached for this period.
