Validate a provider credential and list its resources **before** creating a connector — used by onboarding wizards. Nothing is persisted; credentials stay in-memory.

<RequestExample>

```bash cURL
curl -X POST 'https://api.hydradb.com/connector-discovery'   -H "Authorization: Bearer <your_api_key>" \n  -H "API-Version: 2"   -H "Content-Type: application/json"   -d '{
    "provider": "slack",
    "auth_type": "api_token",
    "credentials": { "api_token": "xoxb-..." }
  }'
```

</RequestExample>
