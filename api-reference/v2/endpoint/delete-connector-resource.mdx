---
title: "Delete Connector Resource"
description: "Stop syncing one resource of a connector."
openapi: "api-reference/v2/openapi.json DELETE /connectors/{id}/resources/{resource_id}"
---

Removes a resource from the connector so it is no longer synced. Objects already synced from it stay in your database; delete them with [Delete Context](/api-reference/v2/endpoint/delete-source) if you no longer want them.

`resource_id` is the id from [List Connector Resources](/api-reference/v2/endpoint/connector-resources). Ids that contain `/` work as they are; URL-encode spaces and other reserved characters. The call returns `deleted: true` even when no such resource was configured.

<RequestExample>

```bash cURL
curl -X DELETE 'https://api.hydradb.com/connectors/{id}/resources/{resource_id}' \
  -H "Authorization: Bearer $HYDRA_DB_API_KEY" \
  -H "API-Version: 2"
```

</RequestExample>

<ResponseExample>

```json 200
{
  "connector_id": "{connector_id}",
  "resource_id": "{resource_id}",
  "deleted": true
}
```

</ResponseExample>
