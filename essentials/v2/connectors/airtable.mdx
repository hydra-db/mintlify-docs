Use the Airtable connector to bring the following content into HydraDB.

## What syncs

The provider description does not enumerate fixed indexed object types. Use the setup notes below when available; the resource picker shows what your connection can select.

## Connect

1. Create an Airtable Personal Access Token with data.records:read and schema.bases:read, then grant that token access to every base you want to select. Correct scopes alone do not grant base access. Legacy API keys are retired.
2. Airtable Personal Access Tokens have no refresh flow. Rotate by creating a replacement with the same scopes and base grants, updating the connector, validating discovery and sync, and then revoking the old token.
3. Pick bases after connecting. Every table record becomes a custom searchable object; record-link fields become graph links, attachment filenames remain in record text, and supported attachment file contents are downloaded through short-lived claim-check pointers and indexed. Oversized or unsupported files remain metadata-only without blocking the record.
4. HydraDB does not currently import Airtable base/workspace collaborators as ACLs. Synced records are tenant-wide unless you configure a HydraDB resource ACL for the selected base.
5. Airtable has no reliable modified timestamp in record payloads, so the connector uses LAST_MODIFIED_TIME() server-side windows. Formula fields that depend on external state can change without a record modification event and may require a full resync.

Use provider `airtable` with [Create Connector](/api-reference/v2/endpoint/create-connector), then [discover resources](/api-reference/v2/endpoint/discover-connector-resources) and [configure the resources](/api-reference/v2/endpoint/configure-connector) you want to sync. The [provider description](/api-reference/v2/endpoint/list-connector-providers) supplies the credential fields for your deployment.

## Common mistakes

- A provider page describes indexed content, not the access granted to your credentials. Select resources the connected account can read.
- Synced content is not automatically private to each person. Review [ACL enforcement](/essentials/v2/connectors#enforce-acl) and set resource access rules where needed.
