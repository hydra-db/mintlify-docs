---
title: "Disable Signing"
description: "Delete the signing secret while keeping the webhook registered."
openapi: "api-reference/openapi.json DELETE /webhooks/indexing/signing-secret"
---

Disables signing by deleting the stored signing secret. The webhook stays registered and continues receiving deliveries, but new deliveries no longer carry `X-HydraDB-Signature`.

<RequestExample>

```python Python SDK
client.webhooks.clear_signing_secret()
```

```typescript TypeScript SDK
await client.webhooks.clearSigningSecret();
```

```bash cURL
curl -X DELETE 'https://api.hydradb.com/webhooks/indexing/signing-secret' \
  -H "Authorization: Bearer $HYDRADB_API_KEY" \
  -H "API-Version: 2"
```

</RequestExample>

<Warning>
Without signing, your receiver cannot use the HydraDB signature to verify a delivery. Update your receiver's verification policy before disabling signing.
</Warning>

Editing the webhook registration preserves its signing secret. Use this endpoint to disable signing, or [Delete Webhook](/api-reference/endpoint/delete-webhook) to stop deliveries entirely. If no webhook is registered, this endpoint returns `404`.
