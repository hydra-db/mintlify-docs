---
title: "Test Webhook"
description: "Send a test delivery to the registered indexing webhook URL."
openapi: "api-reference/v2/openapi.json POST /webhooks/indexing/test"
---

Sends a synthetic event to your registered webhook URL so you can verify connectivity without waiting for a real indexing job. A webhook must already be registered.

<RequestExample>

```bash cURL
curl -X POST 'https://api.hydradb.com/webhooks/indexing/test' \
  -H "Authorization: Bearer $HYDRA_DB_API_KEY" \
  -H "API-Version: 2"
```

</RequestExample>

<ResponseExample>

```json 200
{
  "delivered": true,
  "status_code": 204,
  "message": "Test delivery succeeded."
}
```

</ResponseExample>
