---
title: "List Databases"
description: "List the databases your API key can see, including any that failed to provision."
openapi: "api-reference/v2/openapi.json GET /databases"
---

Lists the databases your API key can see. Active and provisioning databases are in `data.databases`; databases whose provisioning failed are in `data.failed_databases`. A listed database is not necessarily ready: confirm with [Database Status](/api-reference/v2/endpoint/tenant-status) before you ingest.

<RequestExample>

```python Python SDK
response = client.databases.list()
```

```typescript TypeScript SDK
const response = await client.databases.list();
```

```bash cURL
curl -X GET 'https://api.hydradb.com/databases' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2"
```

</RequestExample>

**Failed provisioning:** A database in `data.failed_databases` carries diagnostic entries (see the **Provisioning issue** tab). Fix the reported issue, re-create the database with `POST /databases`, and poll status again before ingesting.
