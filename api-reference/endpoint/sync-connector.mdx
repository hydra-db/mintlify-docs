---
title: "Sync Connector"
description: "Sync a connector now instead of waiting for its schedule."
openapi: "api-reference/openapi.json POST /connectors/{id}/sync"
---

Starts a sync of every configured resource now. Connectors already sync on their own every `sync_interval_seconds` (one hour by default), and [Configure Connector](/api-reference/endpoint/configure-connector) starts the first sync itself. Call this only when you need fresh data sooner.

<RequestExample>

```python Python SDK
run = client.connectors.sync("{connector_id}")
```

```typescript TypeScript SDK
const run = await client.connectors.sync({ id: "{connector_id}" });
```

```bash cURL
curl -X POST 'https://api.hydradb.com/connectors/{id}/sync' \
  -H "Authorization: Bearer $HYDRADB_API_KEY" \
  -H "API-Version: 2"
```

</RequestExample>

<ResponseExample>

```json 202
{
  "workflow_id": "connector-sync-{connector_id}",
  "run_id": "{run_id}"
}
```

</ResponseExample>

A `202` means the sync was started, not that it finished. If a sync is already running, it continues and `run_id` is empty. Follow progress with [Get Connector Status](/api-reference/endpoint/get-connector-status).

## Errors

- `404`: no connector with this id in your organization.
- `409`: the connector is paused, or it has no active resources to sync. [Resume](/api-reference/endpoint/resume-connector) it, or [configure](/api-reference/endpoint/configure-connector) resources first.
- `429`: your plan's sync limit is reached for this period.
