The HydraDB provider for [Nango](https://nango.dev) lets you authenticate once,
then ingest and recall through Nango actions.

## Actions

| Action | What it does |
| --- | --- |
| `ingest-knowledge` | Store a note (`text` plus optional `title`). |
| `recall-context` | Recall matching chunks for a query (text, score, title, id). |

## Authentication

API-key auth (Bearer). The connection credential is your HydraDB API key.
Connection metadata carries `{ database, collection? }`, which the actions read
per call.

## Deploy

1. Add `providers.snippet.yaml` to Nango's `providers.yaml`.
2. Copy `hydradb/` into your `nango-integrations/` project.
3. Deploy:

```bash
npx nango deploy <env>
```

Create a HydraDB connection with an API key and set its metadata, then call
`ingest-knowledge` to store data and `recall-context` to retrieve it.
