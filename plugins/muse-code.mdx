The HydraDB plugin gives [Muse Code](https://dev.meta.ai/docs/muse-code), Meta's
terminal coding agent, memory across sessions. Muse Code's hooks **cannot inject context back to the model**, so
the agent queries HydraDB itself through **MCP** or **skills**, while **hooks** handle
automatic capture and doc sync.

## Quickstart

The MCP setup below enables queries. For automatic capture and doc sync, also [set up the plugin's skills and hooks](https://github.com/hydra-db/hydradb-muse-code-plugin#setup) in your workspace.

<Steps>
  <Step title="Add the MCP server">
    ```json
    {
      "mcp_servers": {
        "hydradb": {
          "transport": "streamable_http",
          "url": "https://mcp.hydradb.com",
          "headers": {
            "Authorization": "Bearer ${HYDRADB_API_KEY}",
            "X-HydraDB-Database": "your-database"
          },
          "enabled": true,
          "mode": "optional"
        }
      }
    }
    ```

    API-key requests to the MCP server require the `X-HydraDB-Database` header
    (your database ID). See the [MCP reference](/plugins/mcp#api-key-headers)
    for all supported headers.
  </Step>
  <Step title="Set credentials and run with the required flags">
    ```bash
    export HYDRADB_API_KEY="your-api-key"
    export HYDRADB_DATABASE="your-database"

    # --trust-workspace loads project skills + hooks; --yolo (or an approval
    # profile) lets the auto-recall skill run node; both are required or recall
    # silently no-ops in headless mode.
    muse exec --trust-workspace --yolo "what did we decide about X?"
    ```

    <Warning>
      Only use `--yolo` in a workspace you trust. It bypasses command approval,
      so any project hooks loaded by `--trust-workspace` run against your local
      environment. In untrusted checkouts, prefer an approval profile that
      permits only the recall skill's `node` call instead of `--yolo`.
    </Warning>
  </Step>
</Steps>

## Configuration

This plugin runs on the same engine as the [Claude Code plugin](/plugins/claude-code), so the [modes](/plugins/claude-code#modes) and other [configuration settings](/plugins/claude-code#configuration) there apply here too.

## How it works

| Extension point | Role |
| --------------- | ---- |
| **MCP** (`mcp_servers`) | Query (`hydradb_query`) and ingest |
| **Skills** (`.claude/skills/`) | `/hydradb …` slash commands (manual query, remember, and sync) |
| **Hooks** (`.muse/hooks.json`) | Automatic capture (`Stop`) and doc sync (`SessionStart`, `PostToolUse`) |
