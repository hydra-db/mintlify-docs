---
title: "Grounding Checklist"
description: "Production checklist for HydraDB grounded answers — citations, inspect, prompts, dual-store, ACL, graph, and evaluation."
---

Use this before shipping any feature that shows HydraDB-backed answers with citations.

---

## Retrieval & scope

- [ ] Feature resolves `database` from a trusted server-side session
- [ ] Knowledge and Memories use correct `collection` / `collections` (dual query when partitions differ)
- [ ] Safety filters sent via `metadata_filters` where required
- [ ] Connector/Slack paths do not use unscoped company-wide queries
- [ ] Multi-channel ACLs use channel-per-collection fanout or parallel equality queries + union (not metadata OR/IN arrays)
- [ ] Ingest status is `graph_creation`/`completed` before relying on results ([Status](/api-reference/v2/endpoint/source-status))

---

## Citation records

- [ ] Every answer turn builds `CitationRecord[]` from the live query payload
- [ ] Records include `chunk_uuid`, `source_title`, preview, and `n`
- [ ] Stable ingest `id` available for inspect (`source_id` in metadata or known mapping)
- [ ] Knowledge vs Memory badges when both stores are used
- [ ] UI and prompt share the same ordered list

---

## Prompt contract

- [ ] Sources numbered explicitly in the prompt
- [ ] System rules: cite-or-refuse, no invented markers
- [ ] Memory sources labeled so they aren’t presented as policy
- [ ] `max_results` sized for citation compliance (often 5–8 to start)
- [ ] Graph relations (if any) marked as non-document evidence

---

## UI & inspect

- [ ] Answer renders only validated markers
- [ ] Invented markers stripped or blocked
- [ ] Citation chips open a source drawer
- [ ] Drawer shows chunk preview without waiting on inspect
- [ ] [`GET /context/inspect`](/api-reference/v2/endpoint/fetch-content) uses correct `id` + `collection`
- [ ] `mode` chosen deliberately (`content` / `url` / `both`)
- [ ] Empty retrieval shows a grounded empty state (no fake fluency)

---

## Security & privacy

- [ ] No citation or inspect path for sources outside the authorized query
- [ ] Private channel / dept content partitioned at query time
- [ ] Logs redacted of sensitive chunk bodies where required
- [ ] Presigned URL TTLs (`expiry_seconds`) are intentional

---

## Graph

- [ ] `graph_context` enabled only when relational UI/prompt needs it
- [ ] Entity paths not shown as document footnotes
- [ ] `chunk_id_to_group_ids` used to attach relations to the selected citation

---

## Evaluation

- [ ] Golden questions with expected source ids / titles
- [ ] Metric for citation precision (markers ⊆ retrieved set)
- [ ] Metric for citation recall on required claims (spot-check)
- [ ] Dual-store cases in the eval set
- [ ] Regression when upsert refreshes change rankings

---

## Ops

- [ ] Trace id correlates user request → query → citation set → inspect
- [ ] Alerts on spike in invented-marker rate or inspect error rate
- [ ] Runbook links to [Failure Modes](/essentials/v2/grounded-answers/failure-modes)
