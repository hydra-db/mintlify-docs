---

import { Field } from "/snippets/field.jsx";

Start an on-demand sync workflow for a connector. Returns the workflow and run IDs so you can track progress. Syncs also run automatically on the connector's interval.

<RequestExample>

```bash cURL
curl -X POST 'https://api.hydradb.com/connectors/<connector_id>/sync' \n  -H "Authorization: Bearer <your_api_key>" \n  -H "API-Version: 2"
```

</RequestExample>
