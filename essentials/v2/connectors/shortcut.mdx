Sync every story and epic in the Shortcut workspace the token can read. There is nothing to select. Each story and each epic is one document with its description. A story links to its epic and to its parent story.

Shortcut permissions are not imported, so every synced item is visible to everyone who can query the collection unless you set an access rule. Comments, tasks, files, owners and requesters are not synced, and a story's workflow state is kept only as a number. Stories and epics deleted in Shortcut stay in HydraDB.

## Permissions

<Warning>
Shortcut permissions are not imported, so **Enforce ACL** is unavailable for this connector. Every synced item is visible to everyone who can query the collection, unless you [set an access rule on the resource](/essentials/v2/connectors#set-your-own-rule-on-a-resource).
</Warning>

- No per-team or per-story visibility is captured. To restrict the whole connector, set an access rule on its resource.

API-key requests must omit `enforce_acl`, including `false`. See [ACL on synced content](/essentials/v2/connectors#5-acl-native-rbac-awareness).

## Keeping in sync

- **First sync:** Reads back the window set by `lookback_days`, 30 days by default, measured on when stories and epics were last updated.
- **New and changed items:** Each sync reads the stories and epics updated since the last sync. A story found both in the workspace and in a legacy Project is stored once.
- **Edits:** An edited story or epic is picked up through its last-updated time and updates its document.
- **Deletions:** Stories and epics deleted in Shortcut stay searchable in HydraDB.

After the first sync, HydraDB syncs every hour by default. Set `sync_interval_seconds` on the connector to change it.

## What gets synced

### On every Shortcut item

<ResponseField name="connector_id" type="Query filter">
Limits a query to this connector's items. Not searchable.
</ResponseField>

<ResponseField name="provider" type="Query filter">
Always `shortcut`. Not searchable.

### Stories

- **One document:** One Shortcut story, including stories in legacy Projects.
- **Title:** The story name, or `Shortcut story` and its id when the name is empty.
- **Text:** The story description. The labels, the creation date and the story id are written as lines too. The title is searchable too.
- **Date:** When the story was last updated, or when it was created if there is no update time.
- **Link back:** The story's page in Shortcut.

<ResponseField name="Story id" type="Searchable text">
The Shortcut story id. It keeps later syncs on the same document.
</ResponseField>

<ResponseField name="labels" type="Searchable text">
Label names, written as the `Labels` line.
</ResponseField>

<ResponseField name="created_at" type="Searchable text">
When the story was created, written as the `Created` line.
</ResponseField>

<ResponseField name="updated_at" type="Result date">
When the story was last updated. Sets the result date and decides when a sync picks the story up. Not searchable.
</ResponseField>

<ResponseField name="epic_id" type="Graph connection">
The epic the story belongs to. Links the story to that epic. Not searchable.
</ResponseField>

<ResponseField name="parent_story_id" type="Graph connection">
The story this story is a sub-task of. Links the story to that parent. Not searchable.
</ResponseField>

<ResponseField name="additional_metadata.shortcut_id" type="Query filter">
The story id. Picks out one story. Not searchable.
</ResponseField>

<Accordion title="Stored only, not searchable (4)">

<ResponseField name="story_type" type="Stored only">
`feature`, `bug` or `chore`. It is not written into the text.
</ResponseField>

<ResponseField name="workflow_state" type="Stored only">
The workflow state's numeric id, not its name.
</ResponseField>

<ResponseField name="completed" type="Stored only">
Whether the story is completed.
</ResponseField>

<ResponseField name="project_id" type="Stored only">
The legacy Project id, often empty.
</ResponseField>

</Accordion>

### Epics

- **One document:** One Shortcut epic.
- **Title:** The epic name, or `Shortcut epic` and its id when the name is empty.
- **Text:** The epic description. The creation date and the epic id are written as lines too. The title is searchable too.
- **Date:** When the epic was last updated, or when it was created if there is no update time.
- **Link back:** The epic's page in Shortcut.

<ResponseField name="Epic id" type="Searchable text">
`epic:` and the epic id, so it never clashes with a story id. Stories link to this id.
</ResponseField>

<ResponseField name="created_at" type="Searchable text">
When the epic was created, written as the `Created` line.
</ResponseField>

<ResponseField name="updated_at" type="Result date">
When the epic was last updated. Sets the result date and decides when a sync picks the epic up. Not searchable.
</ResponseField>

<ResponseField name="additional_metadata.shortcut_id" type="Query filter">
The epic id, without the `epic:` prefix. Picks out one epic. Not searchable.
</ResponseField>

<ResponseField name="additional_metadata.shortcut_kind" type="Query filter">
Always `epic`. Limits a query to epics. Not searchable.
</ResponseField>

<Accordion title="Stored only, not searchable (3)">

<ResponseField name="state" type="Stored only">
`to do`, `in progress` or `done`. It is not written into the text.
</ResponseField>

<ResponseField name="completed" type="Stored only">
Whether the epic is completed.
</ResponseField>

<ResponseField name="type" type="Stored only">
Always `epic`.
</ResponseField>

</Accordion>

## How it fits into the graph

- Stories use the Ticket class.
- Epics use the Ticket class.

[Graph classes](/essentials/v2/connector-providers#graph-classes) explains each class.

**Connections Shortcut creates**

- A story to its epic.
- A story to its parent story.
- No links to items in other tools.

**People and groups**

No people are attached to stories or epics. Owners, requesters and followers are not synced.

**Found in the text**

Story and epic descriptions. HydraDB identifies people, organizations, projects and other named things in this text. To steer what it looks for, use [custom instructions](/essentials/v2/connectors#4-custom-ingestion-instructions).

## Not synced

- Story comments, tasks (checklists), files and linked files.
- Story owners, requesters and followers.
- Readable workflow state names. Only the state's numeric id is kept.
- Members, labels, milestones, iterations, categories, objectives and groups as items of their own.
