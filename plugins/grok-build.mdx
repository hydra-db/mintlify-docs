The HydraDB plugin gives [Grok Build](https://docs.x.ai/build/overview), xAI's
coding agent, long-term memory. Grok Build supports the same hooks as Claude
Code, so the plugin retrieves context before each prompt.

## Quickstart

<Steps>
  <Step title="Set credentials">
    ```bash
    export HYDRADB_API_KEY="your-api-key"
    export HYDRADB_DATABASE="your-database"
    ```
  </Step>
  <Step title="Install in Grok Build">
    The [`xai-org/plugin-marketplace`](https://github.com/xai-org/plugin-marketplace)
    listing is in review. Once merged, `/marketplace` browses and installs it from
    the catalog. To run it from the local checkout today, follow the
    [plugin README](https://github.com/hydra-db/hydradb-grok-plugin).
  </Step>
</Steps>

## Configuration

This plugin runs on the same engine as the [Claude Code plugin](/plugins/claude-code), so the [modes](/plugins/claude-code#modes) and other [configuration settings](/plugins/claude-code#configuration) there apply here too.

## How it works

| Grok Build hook | Engine action |
| --------------- | ------------- |
| `SessionStart` | Print status and start an async workspace sync |
| `UserPromptSubmit` | Query memories and knowledge, and inject the results as `additionalContext` |
| `PostToolUse` (file writes) | Incremental workspace sync |
| `Stop` | Capture the completed turn |

## MCP alternative

To connect over MCP instead, run `grok mcp add hydradb --url https://mcp.hydradb.com`.
The plugin already retrieves context automatically, so MCP is optional.
