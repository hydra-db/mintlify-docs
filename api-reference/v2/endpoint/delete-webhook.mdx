---
title: "Delete Webhook"
description: "Unregister the indexing webhook for this API key."
openapi: "api-reference/v2/openapi.json DELETE /webhooks/indexing"
---

Removes the webhook registration for this API key. HydraDB stops sending `indexing.status_changed` events immediately. Existing delivery history remains available through [List Deliveries](/api-reference/v2/endpoint/list-deliveries).

<RequestExample>

```bash cURL
curl -X DELETE 'https://api.hydradb.com/webhooks/indexing' \
  -H "Authorization: Bearer $HYDRADB_API_KEY" \
  -H "API-Version: 2"
```

</RequestExample>

<ResponseExample>

```json 200
{
  "deleted": true,
  "message": "Webhook unregistered."
}
```

</ResponseExample>

To resume receiving events, register again with [Register Webhook](/api-reference/v2/endpoint/register-webhook).
