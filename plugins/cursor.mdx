The HydraDB plugin for [Cursor](https://cursor.com) recalls relevant notes on
each prompt, syncs your Markdown docs into HydraDB, and saves
conversations as durable memories.

<Steps>
  <Step title="Bootstrap & set credentials">
    ```bash
    git clone https://github.com/hydra-db/hydradb-cursor-plugin.git
    cd hydradb-cursor-plugin
    make bootstrap
    export HYDRADB_API_KEY="your-api-key"
    export HYDRADB_DATABASE="your-database"
    ```

    Requires **Node.js 18+** and npm.
  </Step>
  <Step title="Install in Cursor">
    The public Cursor marketplace listing is in review. For now, load this local
    checkout through Cursor's plugin flow (validate the layout against the
    [Cursor plugin template](https://github.com/cursor/plugin-template)).
  </Step>
</Steps>

It runs on the same engine as the [Claude Code plugin](/plugins/claude-code), so the [modes](/plugins/claude-code#modes) and [config variables](/plugins/claude-code#config-variables) there apply here too.
