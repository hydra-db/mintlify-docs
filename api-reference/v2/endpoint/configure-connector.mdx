---
title: "Configure Connector"
description: "Select the resources to sync and trigger initial sync/backfill."
openapi: "api-reference/v2/openapi.json POST /connectors/{id}/configure"
---

import { Field } from "/snippets/field.jsx";

Choose which discovered resources a connector should sync, set an optional `lookback_days`
window, and kick off the initial sync. When `lookback_days` exceeds the default chunk
window, HydraDB also schedules a historical backfill. Each resource can override the
destination collection via `sub_tenant_id`. Returns how many resources were configured
and whether a backfill was triggered.

<RequestExample>

```bash cURL
curl -X POST 'https://api.hydradb.com/connectors/conn_abc123/configure' \
  -H "Authorization: Bearer <your_api_key>" \
  -H "API-Version: 2" \
  -H "Content-Type: application/json" \
  -d '{
    "lookback_days": 30,
    "resources": [
      { "resource_id": "C0123456789", "name": "general", "sub_tenant_id": "team_docs" }
    ]
  }'
```

</RequestExample>

<ResponseExample>

```json Success
{
  "connector_id": "conn_abc123",
  "configured": 1,
  "backfill": false
}
```

</ResponseExample>
